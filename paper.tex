\begin{abstract}
全スラック基底は，コスト係数の符号に従って非基底変数を配置するだけで計算なしに双対実行可能となるが，それには配置先の上下限が有限である必要がある．非有界な上下限を $\mp M$ に置き換える人工上下限法(双対問題に対する大$M$法)はこの障害を除くが，数値の $M$ を固定する限り，$M$ が十分大きい保証がなく，数値的にも不安定である．本稿では $M$ を固定せず，反復中の諸量を $M$ のアフィン関数として $M\to+\infty$ の極限を記号的に解析する．その結果，反復は，元問題の後退錐を $\|\cdot\|_\infty$ 球で切った\emph{傾き問題}を解く局面と，傾きを固定して得られる\emph{切片問題}を解く局面とにちょうど分かれ，前者の終了時点で元問題が有限な最適値を持ちうるかが判別されることを示す．傾き問題は双対単体法のフェーズ1として知られる補助問題と一致し，この分解は人工上下限法と補助問題によるフェーズ1とを結びつける．これに基づき，2つの局面と必要に応じた後処理からなる\emph{傾き・切片双対二段解法}を導出する．この方法は，初期基底の構築も数値の $M$ も要さずに，双対単体法だけで有限最適解の存在・非有界・実行不能を判別し，最適基底解を構成する．我々の調べた範囲では，主単体法や解き直しに頼らず，双対単体法の反復だけでこの3通りを判別する方法はこれまで示されていない．各局面は通常の LP に対する双対単体法であるから，最急辺規則や Bound Flipping Ratio Test といった双対単体法の高速化技術をそのまま適用でき，局面の分割による追加の計算コストも生じない．
\end{abstract}

\section{はじめに}
\label{sec:intro}

線型計画問題(Linear Programming, LP)に対する単体法は，理論と実装の両面で長年研究されてきた古典的な解法である．単体法を実際に動かすには，制約行列 $A$ から可逆な $m\times m$ 部分行列(基底)$A_B$ を選び，非基底変数をその上限または下限に固定したときに基底変数の値
\[
  x_B = A_B^{-1}\bigl(b - A_N x_N\bigr)
\]
がすべて自身の上下限に収まる，すなわち\emph{実行可能な}初期基底解から出発する必要がある．

この初期基底の構築は，一般には自明ではない．等式制約 $Ax=b$ と一般の範囲制約 $l\le x\le u$($l_j,u_j\in\R\cup\{\pm\infty\}$)からなる\emph{任意の}線型計画問題に対して，計算コストをかけずに実行可能な初期基底を与える一般的な方法は知られておらず，2段階法や大$M$法\cite{dantzig1963}といった補助的な手続きが用いられてきた(第\ref{sec:difficulty}節)．

一方，双対実行可能性に着目すると，コスト $0$ のスラック変数のみからなる全スラック基底では被約費用が $\bar c_j=c_j$ に一致するため，非基底の原変数を
\[
  c_j\ge 0 \ \Longrightarrow\ x_j=l_j,\qquad
  c_j< 0 \ \Longrightarrow\ x_j=u_j
\]
と配置するだけで，\emph{計算なしに}双対実行可能な初期基底が得られる．ただしこの配置は，配置先の上下限が有限であることを要する．実用上の問題では多くの変数が両側有限な上下限を持つから，これを破るのは非有界な側を持つ一部の変数に限られることが多い\cite{koberstein2005}．また実問題を用いた計算実験では，双対単体法は主単体法よりも平均で約2倍高速であったと報告されている\cite{bixby2002}．このため，主単体法の2段階法が与える「実行不可能・非有界・有限最適」の完全な判別を，双対単体法の枠組みの中で行えることには実用上の意義がある．実際，主要なソルバーは「実行不可能または非有界」という区別のつかない判定を返すことがあり，区別には設定を変えた解き直しが用いられている．たとえば Gurobi は，この判定に対してプリソルブの双対縮約を無効にして再最適化することを勧めている\cite{gurobi}．さらに Gurobi の「非有界」という判定は，目的関数を限りなく改善できる方向の存在を示すだけで，実行可能解の存在については何も述べず，実行可能性を確かめるには目的関数を $0$ にして再最適化するよう求めている\cite{gurobi}．CPLEX も同様の判定を持つ\cite{cplex}．

非有界な上下限を大きな定数 $M$ で置き換えてこの障害を除く人工上下限法は，双対単体法のフェーズ1の一つとして知られ，双対問題に対する大$M$法にあたる\cite{wolfe1965,koberstein2005,koberstein2007,huang2021}．しかし $M$ を数値として固定する限り，$M$ が十分大きい保証がないことと，$M$ の混入による数値的不安定性という，主問題の大$M$法と同じ問題が残る．実際 Koberstein\cite{koberstein2005}は，停止時に人工上下限に非基底変数が残れば $M$ を定数倍して再開し，閾値を超えたら非有界と宣言する実装を述べたうえで，適切な $M$ が問題に強く依存し，小さすぎれば再開を繰り返し，大きすぎれば数値的な問題を招くことを理由に，この方法を最終的な実装から外している．

フェーズ1を要さずに3通りの場合を判別できる方法としては，十字法(criss-cross 法)\cite{zionts1969,terlaky1985}と自己双対パラメトリック単体法\cite{dantzig1963,vanderbei2020}が知られている．いずれも任意の基底から出発できるが，主と双対のピボットを組み合わせる方法であり，双対単体法そのものではない．このため，最急辺規則や BFRT のように双対単体法のために発展してきた実装技術をそのまま用いることはできない．十字法については，単体法に多くの効率的な実装があるのと対照的に，実用上効率的な十字法は知られていないとされ，その存在は未解決問題として挙げられている\cite[p.~389]{fukuda1997}．また，主要なソルバーの既定の LP 解法は，双対単体法(HiGHS，CPLEX)や，双対単体法・内点法・主単体法を並行して実行する方法(Gurobi)であり\cite{huangfu2018,cplex,gurobi}，これらの方法は用いられていない．

本稿では，有界化した問題に対する双対単体法を，$M$ を数値として固定せずに $M\to+\infty$ の極限で記号的に解析する．その結果，反復が傾き問題と切片問題を順に解く2つの局面に分かれることを示し，これに基づいて，最急辺規則・Devex規則や Bound Flipping Ratio Test (BFRT) をそのまま用いることのできる2段階の双対単体法(傾き・切片双対二段解法)を導く．

本稿の構成は次の通りである．第\ref{sec:contribution}節で既知の結果と本稿の貢献の区別を述べ，第\ref{sec:prelim}節で上下限制約付き双対単体法の記法を，第\ref{sec:difficulty}節で初期基底の構築に関する既知の方法を確認する．第\ref{sec:method}節では非有界変数を $M$ で有界化し，自明な双対実行可能初期基底を与える．第\ref{sec:symbolic}節では $M\to+\infty$ での挙動を記号的に解析し，元問題の3通りの場合の判別，後処理，非有界境界への非復帰，巡回防止を示す．第\ref{sec:two-phase}節では反復が傾き問題と切片問題を解く2つの局面に分かれることを示して既存の2段階の双対単体法と比較し，第\ref{sec:dual-view}節でこれを双対問題の側から解釈する．第\ref{sec:summary}節で傾き・切片双対二段解法をまとめ，第\ref{sec:experiments}節で数値実験の結果を述べる．

\section{既知の結果と本稿の貢献}
\label{sec:contribution}

本稿の内容には既知の結果の整理と新たな理論とが混在しているため，両者の区別をここで明示する．

\paragraph{既知の結果．}
次の事項は既知であるか，既知の枠組みから直ちに従う．本稿ではこれらを議論の土台として用い，必要なものには本稿の設定での証明を与えるが，主要な貢献とは位置づけない．
\begin{itemize}
\item 自由変数を非基底のまま値 $0$ に置く状態 $Z$ を含む上下限制約付き双対単体法\cite{lemke1954,maros2003}(第\ref{sec:prelim}節)，および初期基底構築のための2段階法・大$M$法・クラッシュ手続き・双対単体法のフェーズ1(第\ref{sec:difficulty}節)．
\item 非有界な上下限を $\pm M$ に置き換える人工上下限法(第\ref{sec:truncation}節)．これは composite simplex 法\cite{wolfe1965}の双対版，すなわち双対問題に対する大$M$法にあたる\cite{koberstein2005,koberstein2007,huang2021}．人工上下限を与えた変数が基底に入った時点で元の上下限に戻す扱い，両側有限な変数のフリップ，BFRT の併用も，数値の $M$ を用いる実装で既に述べられている\cite{koberstein2005}．
\item $M$ を非アルキメデス的な無限大として扱い，係数の辞書式比較で大$M$法を実行する発想\cite{sherali1983,cococcioni2021}，および大$M$法が $M\to+\infty$ で2段階法に一致すること\cite{chvatal1983,bertsimas1997}．補題~\ref{lem:affine}，命題~\ref{prop:consistency}，\ref{prop:trichotomy}および第\ref{sec:dual-view}節の解釈は，これらを双対問題の側に移したものにあたる．
\item 被約費用 $0$ の superbasic 変数を上下限へ動かすクロスオーバーの primal push\cite{megiddo1991,bixby1994,andersen1996}．補題~\ref{lem:cleanup}の後処理はこれと同じ構造を持つ(注~\ref{rem:crossover})．
\item 比検定に対する辞書式規則による巡回防止\cite{dantzig1955}(第\ref{sec:anticycling}節)と，後退錐上の目的関数の符号による有界性の特徴づけ\cite{bertsimas1997}(系~\ref{cor:phaseA})．
\item 傾き問題そのもの．これは双対単体法のフェーズ1として知られる，双対非実行可能性の総和を最小化する補助問題\cite{fourer1994,kostina2002,maros2003pl,koberstein2005,koberstein2007}に一致する(第\ref{sec:slope}節)．
\end{itemize}

\paragraph{本稿の貢献．}
本稿の貢献は，人工上下限法の $M$ を数値として固定せず記号的に扱い，その反復の構造を明らかにしたうえで，実用的な双対単体法として整えることにある．
\begin{enumerate}[label=(\arabic*)]
\item \textbf{双対単体法のみによる完全な判別}(命題~\ref{prop:trichotomy}，\ref{prop:alg})：計算なしに得られる全スラック基底から出発して，双対単体法の反復だけで，元問題が有限な最適値を持つか，実行可能かつ非有界か，実行不可能かを過不足なく判別し，有限な最適値を持つ場合には最適基底解を構成する．数値の $M$ を用いる人工上下限法は $M$ の不足と非有界性を区別できず発見的な判定に頼っており，補助問題による既存の2段階の双対単体法は双対実行不可能と判明した時点で停止して，実行不可能と非有界を区別しない\cite{koberstein2005}(第\ref{sec:known-two-phase}節)．
\item \textbf{傾き・切片への分解}(命題~\ref{prop:two-phase}，\ref{prop:phaseB})：辞書式比較の2つの成分は主反復の中で同時には効かず，反復は，傾き問題に対する双対単体法である局面Aと，傾きを固定して得られる切片問題に対する古典的双対単体法である局面Bとに，反復のレベルで分かれる．傾き問題が人工上下限法の $M$ の係数として現れることにより，これまで別個の手法として扱われてきた人工上下限法(双対問題に対する大$M$法)と補助問題によるフェーズ1(双対問題に対する2段階法)が結びつく(第\ref{sec:dual-two-phase}節)．我々の調べた範囲では，この対応を明示した文献は見当たらない．
\item \textbf{傾き・切片双対二段解法}(第\ref{sec:known-two-phase}，\ref{sec:summary}節)：局面Aで既存のフェーズ1と同じ問題を解いたのち，元問題ではなく切片問題を解く2段階のアルゴリズムを与える．$z^1<0$ の場合も局面Aの基底からそのまま切片問題を解くことで，実行不可能と非有界の区別を双対単体法だけで行う．$z^1=0$ で人工境界に変数が残る場合には，それらを有限な側へ置き直す既存の方法とは別に，$x^1$ を保持したまま切片問題と後処理で最適基底解を得る経路を与え，両者を被約費用 $0$ の変数の置き方の違いとして統一的に理解する．主反復では辞書式比較を用いず，各局面は通常の LP に対する双対単体法であるから，正当性は直接示され(命題~\ref{prop:alg})，最急辺規則・Devex規則や BFRT をそのまま適用できる．
\item \textbf{記号的な後処理}(補題~\ref{lem:cleanup})：primal push を，移動量と基底解が $M$ のアフィン関数となる設定で辞書式に実行し，$M$ を一度も数値として固定せずに元問題の最適基底解を構成する．
\end{enumerate}
一方，脱退行・加入変数の選択規則は分離によって本質的には変わらず(注~\ref{rem:pricing})，既存の方法との効率の比較は第\ref{sec:experiments}節の数値実験で扱う．

\section{準備：上下限制約付き双対単体法}
\label{sec:prelim}

本稿では次の形の線型計画問題を扱う．
\begin{align}
  \min\quad & c^\top x \label{eq:lp}\\
  \text{s.t.}\quad & Ax = b, \notag\\
  & l_j \le x_j \le u_j, \quad j=1,\dots,n, \notag
\end{align}
ここで $A\in\R^{m\times n}$，$b\in\R^m$，$c\in\R^n$，$\operatorname{rank}(A)=m$ であり，$l_j \in \R\cup\{-\infty\}$，$u_j \in \R\cup\{+\infty\}$，$l_j\le u_j$ とする．

\subsection{双対単体法}
\label{sec:dual-simplex}

上下限制約付き双対単体法\cite{lemke1954,maros2003,koberstein2005}について，以下で用いる記法を定める．添字集合を基底 $B$($|B|=m$，$A_B$ 正則)と非基底 $N$ に分割し，各非基底変数に状態 $\eta(j)\in\{L,U,Z\}$ を割り当てて，$\eta(j)=L,U,Z$ に応じて $x_j=l_j,u_j,0$ とする．状態 $L,U$ は有限な下限・上限への配置であり，状態 $Z$ は自由変数を非基底のまま値 $0$ に置く状態である\cite{maros2003}．基底変数は $x_B = A_B^{-1}(b - A_N x_N)$ で定まり，$l_B\le x_B\le u_B$ のとき $(B,\eta)$ は\emph{主実行可能}であるという．単体乗数 $y^\top = c_B^\top A_B^{-1}$ と被約費用 $\bar c_j = c_j - y^\top A_j$ について，すべての $j\in N$ で
\[
  \eta(j)=L \ \Longrightarrow\ \bar c_j\ge 0,\qquad
  \eta(j)=U \ \Longrightarrow\ \bar c_j\le 0,\qquad
  \eta(j)=Z \ \Longrightarrow\ \bar c_j=0
\]
が成り立つとき，$(B,\eta)$ は\emph{双対実行可能}であるという．主・双対ともに実行可能な基底は最適基底である．

双対実行可能な基底から出発する1回の反復は次の通りである．
\begin{enumerate}[label=(\roman*)]
\item \textbf{脱退行}：上下限を逸脱している行 $r$ を選び，その基底変数の添字を $\beta(r)$ とする．$x_{B,r}<l_{\beta(r)}$ なら $\rho=+1$，$x_{B,r}>u_{\beta(r)}$ なら $\rho=-1$ とおく．$x_{B,r}$ は有限であるから，$\beta(r)$ の逸脱した側の境界は必ず有限である．
\item \textbf{ピボット行}：$\alpha^\top := e_r^\top A_B^{-1}A_N$ とし，符号 $\sigma_j$ を $\eta(j)=L$ なら $+1$，$\eta(j)=U$ なら $-1$，$\eta(j)=Z$ なら $\rho\alpha_j$ と反対の符号と定め，$\hat\alpha_j:=\sigma_j\alpha_j$，$\hat c_j:=\sigma_j\bar c_j\ (\ge0)$ とおく．
\item \textbf{比検定}：$\mathrm{Eligible} := \{\, j\in N : l_j<u_j,\ \rho\,\hat\alpha_j < 0 \,\}$ とする(固定変数を除く理由は注~\ref{rem:fixed})．$\mathrm{Eligible}=\emptyset$ ならば問題は実行不可能であり停止する．そうでなければ $q \in \operatorname*{arg\,min}_{j\in \mathrm{Eligible}} \hat c_j/|\hat\alpha_j|$ を加入変数とする．状態 $Z$ の候補は $\hat c_j=0$ であるから比 $0$ で最優先される．
\item \textbf{ピボット}：$\beta(r)$ を逸脱した側の境界に固定して非基底化し，$q$ を基底化する．
\end{enumerate}
すべての行が上下限を満たせば最適基底が得られ，巡回防止規則のもとで反復は有限回で停止する\cite{maros2003,koberstein2005}．

\begin{remark}
\label{rem:Z-invariant}
状態 $Z$ の非基底変数 $k$ の被約費用は反復を通じて $0$ に保たれる．更新 $\bar c_k \gets \bar c_k-\theta\,\alpha_k$($\theta$ は双対ステップ長)において，$\alpha_k\neq0$ ならば $k$ は比 $0$ で加入可能であるから $\theta=0$ となるためである．
\end{remark}

\section{初期基底の構築}
\label{sec:difficulty}

主実行可能な初期基底は一般には自明でなく，2段階法や大$M$法\cite{dantzig1963}，クラッシュ手続き\cite{maros2003}が用いられる．一方，コスト $0$ のスラック変数からなる全スラック基底では $y=0$，したがって $\bar c_j=c_j$ であるから，$c_j\ge0$ なら $\eta(j)=L$，$c_j<0$ なら $\eta(j)=U$ と置くだけで双対実行可能となる．ただしこの配置は配置先の上下限が有限であることを要し，すべての変数が両側有限な有界変数問題などを除けば一般には成り立たない．この障害を除く方法は双対単体法のフェーズ1として知られ，双対非実行可能性の総和の最小化，コストシフト法，非有界な上下限を大きな定数で置き換える人工上下限法(双対問題に対する大$M$法)などがある\cite{wolfe1965,maros2003,koberstein2005,koberstein2007,huang2021}．

大$M$法の数値的な難点は $M$ を具体的な数値として固定することに由来する．固定した基底解に対して大$M$法の目的関数は $M$ のアフィン関数 $z^1M+z^0$ となるから，十分大きな $M$ での比較は係数対 $(z^1,z^0)$ の辞書式比較に帰着し，大$M$法は辞書式(preemptive)最適化と等価である\cite{sherali1983}．Cococcioni と Fiaschi\cite{cococcioni2021}は，$M$ を非アルキメデス的な無限大数として扱い，この考えを主問題の大$M$法のアルゴリズムとして実現している．本稿の着眼は，この発想を双対問題に対する大$M$法，すなわち変数の\emph{上下限}としての $M$ に適用することにある．

\section{$M$ による有界化と自明な双対実行可能基底}
\label{sec:method}

\subsection{前処理：片側のみ非有界な変数の平行移動}
\label{sec:shift-preprocess}

自由変数を含め，非有界な上下限はすべて次節の $M$ による有界化で直接扱い，自由変数を等式制約から消去する前処理は行わない．以降の議論を簡潔にするため，あらかじめ次の前処理を行っておく．各 $j=1,\dots,n$ に対し，シフト量を
\[
  t_j \ :=\
  \begin{cases}
    u_j & (l_j=-\infty,\ u_j<+\infty)\\
    l_j & (l_j>-\infty,\ u_j=+\infty)\\
    0 & (\text{それ以外，すなわち両側とも有限であるか，または両側とも非有界(自由変数)})
  \end{cases}
\]
と定め(スラック変数 $s\in\R^m$ と混同しないよう，シフト量は $t\in\R^n$ と表す)，変数を $x_j = x_j' + t_j$ と置き換える．このとき制約は $Ax' = b-At =: b'$ となり，上下限は $l_j':=l_j-t_j$，$u_j':=u_j-t_j$ となる．とくに，片側のみが非有界であった $j$ については，有限であった側の上下限がちょうど $0$ になる(たとえば $l_j=-\infty,u_j<\infty$ なら $l_j'=-\infty,u_j'=0$；$l_j>-\infty,u_j=+\infty$ なら $l_j'=0,u_j'=+\infty$)．自由変数については $t_j=0$ であり，シフトの前後で $l_j'=-\infty,u_j'=+\infty$ のまま変化しない．目的関数は $c^\top x = c^\top x' + c^\top t$ となるから，元問題の最適値はシフト後の問題の最適値に定数 $c^\top t$ を加えたものである．

以下では，この前処理が済んでいるものとして，記号 $A,b,l,u$ を $b',l',u'$ の意味で用いる．すなわち，片側のみ非有界な変数については，有限な側の上下限が $0$ であると仮定してよい．

\subsection{非有界変数の $M$ による有界化}
\label{sec:truncation}

任意に $M>0$ を固定する．各 $j=1,\dots,n$ に対し，有界化された上下限を
\begin{equation}
  \hat l_j :=
  \begin{cases}
    l_j & (l_j > -\infty)\\
    -M & (l_j = -\infty)
  \end{cases}
  ,\qquad
  \hat u_j :=
  \begin{cases}
    u_j & (u_j < +\infty)\\
    M & (u_j = +\infty)
  \end{cases}
  \label{eq:trunc}
\end{equation}
と定める．元々有限であった上下限はそのまま用い，非有界であった側のみ $\mp M$ に置き換える．$\hat l_j,\hat u_j$ はすべて有限であるから，問題
\begin{equation}
  \min\ c^\top x \quad \text{s.t.}\quad Ax=b,\ \hat l\le x\le \hat u
  \label{eq:lpM}
\end{equation}
は上下限制約付き単体法がそのまま適用できる有界な問題となる．明らかに $[\hat l,\hat u]\subseteq[l,u]$ であるから，\eqref{eq:lpM}の実行可能領域は元の問題\eqref{eq:lp}の実行可能領域の部分集合である．また $M_1\le M_2$ ならば $[\hat l(M_1),\hat u(M_1)]\subseteq[\hat l(M_2),\hat u(M_2)]$ であり，\eqref{eq:lpM}の実行可能領域は $M$ に関して単調非減少である．

\subsection{ゼロ固定スラック変数による自明な初期基底}
\label{sec:init-basis}

等式制約 $Ax=b$ に，各行に対応するスラック変数 $s\in\R^m$ を追加し，
\[
  Ax + s = b,\qquad l_s = u_s = 0 \ \ (\text{すなわち } s\equiv 0 \text{ に固定})
\]
と書き換える．拡大された変数ベクトルは $(x,s)\in\R^{n+m}$ であり，拡大制約行列は $\hat A = [\,A \mid I_m\,]$ である．$s$ のコストは $0$ とする．

このとき，$B_0:=\{n+1,\dots,n+m\}$(スラック変数の添字集合)を初期基底として採用すると，$A_{B_0}=I_m$ であるから，
\[
  A_{B_0}^{-1} = I_m
\]
であり，逆行列の計算すら不要である．非基底(原変数)の状態は，コスト係数の符号のみから
\begin{equation}
  \eta(j) =
  \begin{cases}
    L, \ x_j=\hat l_j & c_j>0,\ \text{または}\ (c_j=0\ \text{かつ}\ l_j>-\infty)\\
    U, \ x_j=\hat u_j & c_j<0,\ \text{または}\ (c_j=0\ \text{かつ}\ l_j=-\infty,\ u_j<+\infty)\\
    Z, \ x_j=0 & c_j=0\ \text{かつ}\ l_j=-\infty,\ u_j=+\infty
  \end{cases}
  \qquad (j=1,\dots,n)
  \label{eq:init-status}
\end{equation}
と定める．コスト $0$ の変数は $L,U,Z$ のいずれに置いても双対実行可能性の条件を満たすから，$M$ に依存しない値をとる配置を選ぶ．すなわち，有限な側があればそこへ置き，自由変数は状態 $Z$ で値 $0$ に置く．こうして，初期配置で $M$ に依存する値をとる変数は，コストの符号が無限側への配置を真に要求する変数の集合
\[
  S \ :=\ \{\,j : l_j=-\infty,\ c_j>0\,\} \ \cup\ \{\,j : u_j=+\infty,\ c_j<0\,\}
\]
に属するものだけとなる．このとき基底(スラック)変数の値は
\begin{equation}
  x_{B_0} = s = b - A x_N
  \label{eq:init-basic}
\end{equation}
により直接計算される．$s$ は一般には $0$ に一致せず，\eqref{eq:init-basic}の値は $s$ 自身の上下限 $[0,0]$ を逸脱しうるが，これは以下に見るように双対実行可能性の観点からは問題にならない．

\begin{proposition}[初期基底の双対実行可能性]
\label{prop:dual-feasible-init}
\eqref{eq:init-status}で定めた $(B_0,\eta)$ は，問題~\eqref{eq:lpM}に対して双対実行可能である．
\end{proposition}

\begin{proof}
基底コストは $c_{B_0}=0$($s$ のコストが $0$)であり，$A_{B_0}=I$ であるから，単体乗数は $y^\top = c_{B_0}^\top A_{B_0}^{-1} = 0$ である．したがって非基底の原変数 $j$ の被約費用は
\[
  \bar c_j = c_j - y^\top A_j = c_j
\]
となり，コストそのものに一致する．\eqref{eq:init-status}より，$\eta(j)=L$ ならば $c_j>0$ または($c_j=0$ かつ $l_j>-\infty$)であり，いずれの場合も $c_j\ge0$，ゆえに $\bar c_j=c_j\ge0$．同様に $\eta(j)=U$ ならば $c_j<0$ または($c_j=0$ かつ $l_j=-\infty$)であり，いずれの場合も $c_j\le0$，ゆえに $\bar c_j=c_j\le0$．$\eta(j)=Z$ ならば $c_j=0$ ゆえ $\bar c_j=0$．したがって双対実行可能性の条件を満たす．基底変数($s$)の被約費用は定義より恒等的に $0$ であり，条件を課す必要がない．
\end{proof}

ここで本質的に用いているのは，(a) $c_{B_0}=0$ かつ $A_{B_0}=I$ より単体乗数が自明に $y=0$ となること，(b) 配置先の上下限 $\hat l_j,\hat u_j$ がいずれも有限であること，の2点であり，(b)は $M$ による有界化によって保証されている．

\subsection{$M$ を固定した場合のアルゴリズム}
\label{sec:M-algorithm}

以上から，$M$ を固定して有界化した問題~\eqref{eq:lpM}に対するアルゴリズムは以下のようになる．

\textbf{Step~1(初期基底の構成)．} 式~\eqref{eq:init-status}，\eqref{eq:init-basic}により，基底を $B\gets B_0=\{n+1,\dots,n+m\}$(スラック変数の添字)，非基底の原変数の状態を $\eta$，非基底値を $x_N$，基底値を $x_B=s=b-Ax_N$ と定める．命題~\ref{prop:dual-feasible-init}により，この $(B,\eta)$ は計算なしに双対実行可能である．

\textbf{Step~2(反復)．} 以下の(a)--(d)を，(a)で終了と判定されるまで繰り返す．

\begin{enumerate}[label=(\alph*)]
\item \textbf{主実行可能性の判定(終了条件)．} 基底変数の値は $x_B=A_B^{-1}(b-A_Nx_N)$ であり，非基底値は $\eta(j)=L,U,Z$ に応じて $x_j=\hat l_j,\hat u_j,0$ である(初回は式~\eqref{eq:init-basic}に一致し，以後は(d)のピボットで逐次更新すればよい)．とくに，元々 $l_j=-\infty$ で $\eta(j)=L$ ならば $x_j=-M$，元々 $u_j=+\infty$ で $\eta(j)=U$ ならば $x_j=M$ である．$\beta(i)$ を行 $i$ に対応する基底変数の添字とし，逸脱行の集合を
\[
  V \ :=\ \bigl\{\, i\in\{1,\dots,m\} \ :\ x_{B,i} < \hat l_{\beta(i)} \ \text{または}\ x_{B,i} > \hat u_{\beta(i)} \,\bigr\}
\]
と定める．$V=\emptyset$ ならば $(B,\eta,x)$ は問題~\eqref{eq:lpM}に対して主実行可能であり，双対実行可能性はStep~1で成立し(b)--(d)で保たれる(第\ref{sec:dual-simplex}節)から，問題~\eqref{eq:lpM}の最適解である．アルゴリズムを終了する．$V\neq\emptyset$ の場合は(b)に進む．

\item \textbf{脱退変数の選択．} まず，各 $i\in V$ に対し逸脱量を
\[
  \Delta_i \ :=\ \max\bigl(\hat l_{\beta(i)}-x_{B,i},\ x_{B,i}-\hat u_{\beta(i)}\bigr) \ (>0)
\]
とおく．脱退行 $r\in V$ は，最大逸脱則(Dantzig則) $r\in\operatorname*{arg\,max}_{i\in V}\Delta_i$ のほか，行の重み $\gamma_i:=\sum_{j\in N}\alpha_{ij}^2$($\alpha_{ij}:=(A_B^{-1}A_N)_{ij}$)で正規化した $\Delta_i^2/\gamma_i$ を最大化する最急辺規則\cite{forrestgoldfarb1992}や，$\gamma_i$ を安価に更新される近似重み $\tilde\gamma_i$ で置き換えた Devex規則\cite{harris1973}で選ぶ(Dantzig則の $M\to\infty$ 版は第\ref{sec:M-infty}節で与え，最急辺規則・Devex規則は第\ref{sec:summary}節の最終的なアルゴリズムで各局面の問題にそのまま用いる)．逸脱の方向 $\rho$ は第\ref{sec:dual-simplex}節(i)と同様に，$\hat l,\hat u$ に関して定める．

\item \textbf{ピボット行の計算と比検定．} 第\ref{sec:dual-simplex}節(ii)と同様に $\alpha^\top := e_r^\top A_B^{-1}A_N$，$\sigma_j$，$\hat\alpha_j:=\sigma_j\alpha_j$，$\hat c_j:=\sigma_j\bar c_j\,(\ge0)$ を定め，加入可能な非基底変数の集合
\[
  \mathrm{Eligible} \ :=\ \{\, j\in N : \hat l_j<\hat u_j,\ \rho\,\hat\alpha_j < 0 \,\}
\]
を計算する(固定変数を除く．次の注~\ref{rem:fixed})．$\mathrm{Eligible}=\emptyset$ ならば，現在の $M$ のもとで問題~\eqref{eq:lpM}は実行不可能であり，アルゴリズムを終了する．そうでなければ
\[
  q \ \in\ \operatorname*{arg\,min}_{j\in \mathrm{Eligible}} \frac{\hat c_j}{|\hat\alpha_j|}
\]
により加入変数 $q$ を選ぶ(状態 $Z$ の候補は比 $0$ で最優先される)．

\item \textbf{ピボット．} $\beta(r)$ を非基底化し，$\rho=+1$ ならば $\hat l_{\beta(r)}$ に，$\rho=-1$ ならば $\hat u_{\beta(r)}$ に固定する．$q$ を基底化し，基底 $B$，逆行列 $A_B^{-1}$，基底解 $x_B$，非基底値 $x_N$，非基底の状態 $\eta$ を更新して(a)に戻る．
\end{enumerate}

\begin{remark}[固定変数の除外]
\label{rem:fixed}
$\hat l_j=\hat u_j$ なる非基底変数(固定変数)は，被約費用の符号に合わせて状態 $L,U$ を付け替えるだけで値を変えずに双対実行可能性を満たすから，比検定から除いてよい\cite{koberstein2005}．とくにスラック変数 $s$ は $l_s=u_s=0$ であるから，いったん脱退したスラック変数は二度と基底に戻らない．
\end{remark}

このアルゴリズムを数値の $M$ を固定して実行すると，2つの問題が生じる．第一に，非基底値 $\mp M$ が $x_B$ の計算や逸脱量の判定・比検定に混入し，古典的な大$M$法と同種の数値的不安定性を招く．第二に，より本質的に，$M$ が十分大きい保証がない限り判定そのものが誤りうる．元問題が非有界であっても，$M$ が小さすぎれば\eqref{eq:lpM}は非有界方向を断ち切った有界な問題となり，有限な最適解が返される．次節では，$M$ の値を固定せず，$M\to+\infty$ での挙動を記号的に解析することでこれらの問題を回避する．

\section{$M\to+\infty$ における記号的解析}
\label{sec:symbolic}

\subsection{基底解のアフィン性と辞書式比較}
\label{sec:M-infty}

第\ref{sec:difficulty}節で述べたように，大$M$法では十分大きな $M$ での比較が係数対の辞書式比較に帰着する．本稿の $M$ は双対問題におけるペナルティ係数にあたるから(第\ref{sec:dual-view}節)，同様に $M\to+\infty$ の極限を係数の辞書式比較として扱うことができる．

Step~2(c)(d)は，現在の基底 $B$ と非基底の状態 $\eta$ のみから定まり，$M$ の数値には依存しない．$M$ が関与するのは，$\hat l,\hat u$ と，それに応じて定まる $x_N,x_B$，およびStep~2(a)(b)の判定・選択のみである．以下では，組合せ的状態 $(B,\eta)$ を固定したまま，これらが $M$ のアフィン関数になることを用いて解析する．

\begin{lemma}[$x_B$ の $M$ に関するアフィン性]
\label{lem:affine}
組合せ的状態 $(B,\eta)$ を固定する．非基底値 $x_N(M)$ の各成分は
\[
  x_j(M) =
  \begin{cases}
    l_j & (\eta(j)=L,\ l_j>-\infty)\\
    -M & (\eta(j)=L,\ l_j=-\infty)\\
    u_j & (\eta(j)=U,\ u_j<+\infty)\\
    M & (\eta(j)=U,\ u_j=+\infty)\\
    0 & (\eta(j)=Z)
  \end{cases}
\]
であるから，$x_N(M) = x_N^0 + Mx_N^1$ と書ける．ここで $x_N^0\in\R^{|N|}$，$x_N^1\in\{-1,0,1\}^{|N|}$ は $(B,\eta)$ のみに依存し $M$ に依存しない定ベクトルで，$x_j^1=-1\,(\eta(j)=L,l_j=-\infty)$，$x_j^1=+1\,(\eta(j)=U,u_j=+\infty)$，それ以外(状態 $Z$ を含む)は $x_j^1=0$ である．したがって
\[
  x_B(M) \ =\ A_B^{-1}\bigl(b-A_Nx_N(M)\bigr) \ =\ \underbrace{A_B^{-1}(b-A_Nx_N^0)}_{=:x_B^0}\ +\ M\underbrace{\bigl(-A_B^{-1}A_Nx_N^1\bigr)}_{=:x_B^1}
\]
は $M$ のアフィン関数であり，係数 $x_B^0,x_B^1\in\R^m$ は $(B,\eta)$ にのみ依存する．すなわち $x^0:=(x_N^0,x_B^0)$，$x^1:=(x_N^1,x_B^1)$ とおけば $x(M)=x^0+Mx^1$ である．
\end{lemma}

以下では一貫して，$M$ のアフィン関数 $f(M)$ の\emph{傾き}($M$ の係数)を上付きの $1$ で，\emph{切片}(定数項)を上付きの $0$ で表し，$f(M)=f^1M+f^0$ と書く．基底解 $x(M)=x^0+Mx^1$ はこの記法に従っている．

同様に，$\hat l_{\beta(i)}(M),\hat u_{\beta(i)}(M)$ も式~\eqref{eq:trunc}よりそれぞれ($l_{\beta(i)}$ または $-M$)，($u_{\beta(i)}$ または $M$)というアフィン関数であるから，Step~2(a)の逸脱量
\[
  v_i^-(M) := \hat l_{\beta(i)}(M) - x_{B,i}(M), \qquad
  v_i^+(M) := x_{B,i}(M) - \hat u_{\beta(i)}(M)
\]
も，補題~\ref{lem:affine}よりいずれも $M$ のアフィン関数である．上の記法に従い，これを $v_i^-(M)=v_i^{-,1}M+v_i^{-,0}$，$v_i^+(M)=v_i^{+,1}M+v_i^{+,0}$ と書く($v_i^{\pm,1},v_i^{\pm,0}\in\R$ は $(B,\eta)$ のみに依存する定数)．

\begin{definition}[アフィン関数の辞書式順序]
2つのアフィン関数 $f(M)=f^1M+f^0$，$h(M)=h^1M+h^0$ に対し，
\[
  f \ \succ\ h \quad :\Longleftrightarrow\quad f^1>h^1,\ \ \text{または}\ \ (f^1=h^1\ \text{かつ}\ f^0>h^0)
\]
と定める(すなわち係数ベクトル $(f^1,f^0),(h^1,h^0)$ の辞書式順序で比較する)．
\end{definition}

$f\succ h$ ならば，ある $M^\dagger(f,h)>0$ が存在し，すべての $M\ge M^\dagger(f,h)$ で $f(M)>h(M)$ が成り立つ($f^1\neq h^1$ なら $M^\dagger=|f^0-h^0|/|f^1-h^1|$ でよく，$f^1=h^1,\,f^0>h^0$ なら任意の $M>0$ で成り立つ)．$h\succ f$ の場合も同様であり，$(f^1,f^0)=(h^1,h^0)$ のときは $f\equiv h$ である．この $\succ$ は有限個のアフィン関数の集合上の全順序を与え，それらすべての対に対する $M^\dagger(f,h)$ の最大値を $M^\dagger$ とおけば，$M\ge M^\dagger$ である限り，数値比較の結果はすべて $\succ$ による比較と一致する．

これを用いて，Step~2(a)(b)を，具体的な $M$ の値を固定せずに次のように書き換えることができる．

\begin{enumerate}
\item[(a$'$)] \textbf{主実行可能性の判定(終了条件，$M\to\infty$ 版)．} $V_\infty := \{\, i\in\{1,\dots,m\} : v_i^- \succ 0 \ \text{または}\ v_i^+ \succ 0 \,\}$ とおく(ここで $0$ は恒等的に $0$ であるアフィン関数，すなわち係数ペア $(0,0)$ を表す)．$V_\infty=\emptyset$ ならば，$M\ge M^\dagger$ のすべてで主実行可能性が成り立ち，アルゴリズムは終了する．
\item[(b$'$)] \textbf{脱退変数の選択($M\to\infty$ 版Dantzig則)．} 各 $i\in V_\infty$ に対し，$v_i^-,v_i^+$ のうち $\succ$ で大きい方を $w_i$ とする．
\[
  r \ \in\ \operatorname*{arg\,max}_{i\in V_\infty}{}^{\succ}\, w_i
\]
により(辞書式順序 $\succ$ に関する最大元として)脱退行 $r$ を選ぶ．$w_r=v_r^-$ であれば $\rho=+1$，$w_r=v_r^+$ であれば $\rho=-1$ とする(両者が等しい場合の同点処理は，添字の小さい方を優先するなど，Bland 則に準じた規則で決定的に定める)．
\end{enumerate}

\begin{proposition}[十分大きな $M$ での数値計算との一致]
\label{prop:consistency}
組合せ的状態 $(B,\eta)$ を固定したとき，(a$'$)(b$'$)による判定・選択は，ある(その状態にのみ依存する)$M^\dagger>0$ が存在して，すべての $M\ge M^\dagger$ における(a)(b)の数値計算による判定・選択と一致する．
\end{proposition}

\begin{proof}
$V_\infty$ の各元の判定，および $\arg\max^\succ$ による $r$ の選択は，有限個のアフィン関数の対 $(v_i^-,v_i^+,\,0)$ の間の $\succ$ による比較のみから決まる．上述の通り，これらの比較はある共通の $M^\dagger$ 以降，数値比較 $v_i^\pm(M)>0$，$\max_i(\cdot)$ と一致する．
\end{proof}

Step~2(c)(d)は $M$ に依存しないから，(a$'$)(b$'$)によって次の状態 $(B',\eta')$ が(数値としての $M$ を固定することなく)一意に定まり，これを繰り返すことで，組合せ的な状態遷移の列 $(B^{(0)},\eta^{(0)}) \to (B^{(1)},\eta^{(1)}) \to \cdots$ が得られる．この列は巡回防止規則(第\ref{sec:anticycling}節)のもとで有限回で停止し，各反復の $M^\dagger$ の最大値を改めて $M^\dagger$ とおけば，$M\ge M^\dagger$ なるすべての $M$ に対して，Step~2を数値計算した場合の反復列はこの組合せ的な遷移列と完全に一致する．すなわち，$M\to+\infty$ での挙動は，係数対の辞書式比較のみによって計算できる．この遷移列の最終状態 $(B^\ast,\eta^\ast)$ が，そのまま十分大きな $M$ に対する\eqref{eq:lpM}の最適基底である．以下，$M$ を記号的に扱うこの反復(Step~2の(a$'$)(b$'$)(c)(d))を\emph{記号的人工上下限法}と呼ぶ．

\subsection{3通りの場合の判別}
\label{sec:trichotomy}
状態遷移列が最終状態 $(B^\ast,\eta^\ast)$((a$'$)で $V_\infty=\emptyset$ となる状態)に到達したとする．補題~\ref{lem:affine}の $x(M)=x^0+Mx^1$ を用いると，問題~\eqref{eq:lpM}の最適値は
\[
  z(M) \ =\ c_B^\top x_B(M) + c_N^\top x_N(M)
     \ =\ \underbrace{c^\top x^0}_{=:z^0} \ +\ M\ \underbrace{c^\top x^1}_{=:z^1}
\]
と，やはり $M$ のアフィン関数として表される．ここで $z^0,z^1\in\R$ は $(B^\ast,\eta^\ast)$ にのみ依存し，$M\ge M^\dagger$ ではこれが問題~\eqref{eq:lpM}の最適値そのものである．\eqref{eq:lpM}の実行可能領域は $M$ に関して単調非減少であるから(第\ref{sec:truncation}節)，$z(M)$ は単調非増加であり，したがって $z^1\le0$ が常に成り立つ．

\begin{lemma}[実行可能領域の合併]
\label{lem:union}
$F:=\{x:Ax=b,\ l\le x\le u\}$(元問題~\eqref{eq:lp}の実行可能領域)とする．このとき
\[
  F \ =\ \bigcup_{M>0} F_M, \qquad F_M := \{x:Ax=b,\ \hat l(M)\le x\le \hat u(M)\}\ (\text{すなわち\eqref{eq:lpM}の実行可能領域})
\]
が成り立つ．
\end{lemma}

\begin{proof}
($\supseteq$)：任意の $M>0$ に対し $[\hat l(M),\hat u(M)]\subseteq[l,u]$ であるから $F_M\subseteq F$．

($\subseteq$)：$x\in F$ を任意にとる．$x$ は(拡大実数値ではなく)有限な実ベクトルであるから $\|x\|_\infty<\infty$．$M\ge\|x\|_\infty$ ととれば，$x_j$ がもともと有限な上下限を持つ座標では $\hat l_j(M)=l_j\le x_j\le u_j=\hat u_j(M)$ がそのまま成り立ち，もともと非有界であった座標では $|x_j|\le M$ より $-M\le x_j\le M$ が成り立つ．ゆえに $x\in F_M$．
\end{proof}

傾き $z^1$ の符号と停止結果から，元問題の3通りの場合を過不足なく判別できる．

\begin{proposition}[3通りの場合の判別]
\label{prop:trichotomy}
組合せ的状態遷移列が，ある $M^\dagger>0$ 以降で最終状態 $(B^\ast,\eta^\ast)$ に到達し，そこで(a$'$)(b$'$)(c)(d)が停止するとする．このとき次が成り立つ．
\begin{enumerate}[label=(\roman*)]
\item 停止結果が \textsc{Infeasible} である $\iff$ $F=\emptyset$．
\item 停止結果が \textsc{Optimal} かつ $z^1<0$ である $\iff$ $F\neq\emptyset$ かつ $\inf_{x\in F}c^\top x=-\infty$(元問題は実行可能かつ非有界)．
\item 停止結果が \textsc{Optimal} かつ $z^1=0$ である $\iff$ $F\neq\emptyset$ かつ $\inf_{x\in F}c^\top x$ が有限であり，このとき $\inf_{x\in F}c^\top x=z^0$ である．
\end{enumerate}
\end{proposition}

\begin{proof}
命題~\ref{prop:consistency}とその後の議論により，停止結果は $M\ge M^\dagger$ のすべてで共通であり，$F_M$ は $M\ge M^\dagger$ のすべてで空であるか，すべてで非空かつ最小値 $z(M)=z^0+z^1M$ を持つ．また $M_1\le M_2$ ならば $F_{M_1}\subseteq F_{M_2}$(単調性)である．

(i)：($\Leftarrow$) $F=\emptyset$ ならば，補題~\ref{lem:union}より任意の $M$ で $F_M\subseteq F=\emptyset$．とくに $M\ge M^\dagger$ で \eqref{eq:lpM} は実行不可能であり，停止結果は \textsc{Infeasible} である．
($\Rightarrow$) 停止結果が \textsc{Infeasible} であれば $F_{M^\dagger}=\emptyset$．単調性より $M<M^\dagger$ でも $F_M\subseteq F_{M^\dagger}=\emptyset$．ゆえに補題~\ref{lem:union}より $F=\bigcup_M F_M=\emptyset$．

(ii)(iii)：以下，(i)より $F\neq\emptyset$ であるとしてよく，したがって停止結果は \textsc{Optimal} である．補題~\ref{lem:union}と単調性より，任意の $x\in F$ に対し $M_x:=\max(M^\dagger,\|x\|_\infty)$ とおけば $x\in F_{M_x}$(補題~\ref{lem:union}の証明と同じ議論)であり，ゆえに
\[
  c^\top x \ \ge\ \min_{F_{M_x}} c^\top x \ =\ z(M_x) \ =\ z^0+z^1M_x .
  \tag{$\ast$}
\]

($z^1<0 \Rightarrow$ 非有界)：$F_M\subseteq F$ より $\inf_{x\in F}c^\top x\le z(M)=z^0+z^1M\to-\infty\ (M\to\infty)$．

(非有界 $\Rightarrow z^1<0$)：対偶を示す．$z^1=0$ とする．$F\neq\emptyset$ かつ非有界であれば，任意の $N>0$ に対しある $x_N\in F$ が存在して $c^\top x_N<-N$．$(\ast)$ を $x=x_N$ に適用すると $c^\top x_N\ge z^0+z^1M_{x_N}=z^0$($z^1=0$ のため $M_{x_N}$ の値によらない)．ゆえに $z^0\le c^\top x_N<-N$．$N$ は任意だから $z^0=-\infty$ となるが，$z^0$ は補題~\ref{lem:affine}より有限な実数として定義されているから矛盾．ゆえに $F$ が非有界ならば $z^1\neq0$．先に示した $z^1\le0$ と合わせて $z^1<0$．

以上より，$F\neq\emptyset$ のとき「$z^1<0\iff$ 非有界」，したがって($z^1\le0$ の二分法により)「$z^1=0\iff$ 有限な最適値を持つ」が従う．

最後に，$z^1=0$ の場合に $\inf_{x\in F}c^\top x=z^0$ であることを示す．任意の $x\in F$ に対し，$(\ast)$ で $z^1=0$ を用いれば $c^\top x\ge z^0$．一方，任意に $M\ge M^\dagger$ を一つ固定すると，補題~\ref{lem:union}の証明(($\supseteq$)方向)と同じ議論により，このときの基底解 $(x_B(M),x_N(M))$ は $F_M\subseteq F$ に属し，かつ $c_B^\top x_B(M)+c_N^\top x_N(M)=z(M)=z^0+z^1M=z^0$(最後の等号は $z^1=0$ による)．ゆえに $z^0$ は $F$ 上で実際に達成される下界であり，$z^0=\min_{x\in F}c^\top x$ が従う．
\end{proof}

命題~\ref{prop:trichotomy}により，数値の $M$ を用いる人工上下限法で問題となった $M$ の不足と非有界性の区別(第\ref{sec:intro}節)は，停止時の傾き $z^1$ の符号だけで，再開なしに厳密に行える．

命題~\ref{prop:trichotomy}(iii)の場合，最適\emph{基底} $(B^\ast,\eta^\ast)$ と最適値 $z^0$ は $M$ を固定せずに得られるが，具体的な最適解ベクトルを取り出すには，以下に述べる後処理を要する．

\subsection{人工上下限に残った非基底変数の後処理}
\label{sec:cleanup}
最終状態 $(B^\ast,\eta^\ast)$ で非基底のまま残る変数 $j$ のうち，$x_j^1\neq0$(非有界であった側に置かれ，$x_j(M)=\mp M$ となっている)ものを考える．このような $j$ は，片側のみ非有界な変数(有限な側の上下限は前処理によりちょうど $0$)か自由変数のいずれかである．

標準的な単体法の議論により，$x_B(M)=A_B^{-1}(b-A_Nx_N(M))$ を用いて $z(M)=c_B^\top x_B(M)+c_N^\top x_N(M)$ を書き直すと，
\[
  z(M) \ =\ c_B^\top A_B^{-1}b \ +\ \sum_{j\in N} \bar c_j\, x_j(M)
\]
となる．非基底値 $x_j(M)$ のうち $M$ に依存する項(人工上下限に置かれた $j$)だけを取り出せば，$z(M)=z^0+z^1M$ の傾きは
\[
  z^1 \ =\ \sum_{\substack{j\in N,\ \eta(j)=L\\ l_j=-\infty}} (-\bar c_j) \ +\ \sum_{\substack{j\in N,\ \eta(j)=U\\ u_j=+\infty}} \bar c_j
\]
と表される(この式は，補題~\ref{lem:affine}の $z^1=c^\top x^1$ を被約費用で書き直したものに等しい)．双対実行可能性より，$\eta(j)=L$ の各項は $\bar c_j\ge0$ ゆえ $-\bar c_j\le0$，$\eta(j)=U$ の各項は $\bar c_j\le0$ であるから，$z^1$ は\emph{非正の項の和}であり，これは先に示した $z^1\le0$ の別証明でもある．とくに，
\[
  z^1=0 \quad\Longleftrightarrow\quad x_j^1\neq0\ \text{なるすべての非基底変数 $j$ について}\ \bar c_j=0
\]
が成り立つ．これは，非有界な方向に置かれた非基底変数の被約費用は $0$ でなければならないという標準的な最適性条件に他ならない．

しかし，$x_j^1\neq0$ なる非基底変数が存在する場合，形式的に $M=0$ を代入して得られる点 $x^0=(x_N^0,x_B^0)$ は，一般には元問題の実行可能解にならない．非基底値 $x_N^0$ は前処理により真の上下限上にあるが，基底値 $x_B(M)=x_B^0+Mx_B^1$ の主実行可能性は $M\ge M^\dagger$ でしか保証されず，$M=0$ まで外挿すると上下限を逸脱しうるからである．次の補題は，$\bar c_j=0$ という性質を利用してこの問題を解消する．

\begin{lemma}[人工上下限に置かれた非基底変数の主比検定による除去]
\label{lem:cleanup}
$z^1=0$ とする．組合せ的状態 $(B,\eta)$ は元問題~\eqref{eq:lp}に対して双対実行可能であり，その基底解 $x(M)$ の各成分は $M$ のアフィン関数で，十分大きなすべての $M$ で元問題の上下限 $l\le x(M)\le u$ を満たすとする(最終状態 $(B^\ast,\eta^\ast)$ はこれを満たす．$F_M\subseteq F$ であり，双対実行可能性は $M$ に依存しないため)．$j\in N$ を $x_j^1\neq0$ なる非基底変数とする($z^1=0$ より $\bar c_j=0$)．前処理により，$j$ の現在値は $x_j(M)=x_j^1M$ であり，$j$ が片側のみ非有界ならその有限な側の上下限はちょうど $0$ である．$x_j$ を $x_j^1M$ から $0$ へ向けて移動量 $t\in[0,M]$ だけ動かす($x_j\gets x_j^1(M-t)$)と，基底変数は
\[
  x_B \ \gets\ x_B(M) + x_j^1\,t\,\alpha_{\cdot j}, \qquad \alpha_{\cdot j}:=A_B^{-1}A_j
\]
と変化する．各行 $i$ について，$x_{B,i}$ が $\beta(i)$ の\emph{真に有限な}境界に到達する移動量を
\[
  t_i :=
  \begin{cases}
    \dfrac{u_{\beta(i)}-x_{B,i}(M)}{x_j^1\alpha_{ij}} & (x_j^1\alpha_{ij}>0,\ u_{\beta(i)}<+\infty)\\[2ex]
    \dfrac{x_{B,i}(M)-l_{\beta(i)}}{-x_j^1\alpha_{ij}} & (x_j^1\alpha_{ij}<0,\ l_{\beta(i)}>-\infty)
  \end{cases}
\]
と定め(それ以外の行は移動を妨げない．人工境界 $\pm M$ は元問題には存在しないので考慮しない)，$t^\ast$ を $\{M\}\cup\{t_i\}$ の $\succ$ に関する最小元とする(いずれも $M$ のアフィン関数である．同順位は $M$ を優先し，$t_i$ どうしは添字の小さい方を優先する)．そのうえで，
\begin{enumerate}[label=(\Alph*)]
\item $t^\ast=M$ ならば，$x_j$ を $0$ に置く．すなわち，$j$ が片側のみ非有界であればその有限な側(状態 $L$ または $U$)に，自由変数であれば状態 $Z$ に置く．基底は変えない．
\item $t^\ast=t_r\prec M$ ならば，$j$ を加入変数，$\beta(r)$ を脱退変数とするピボットを行い，$\beta(r)$ を到達した有限境界に固定する(上限なら状態 $U$，下限なら状態 $L$)．
\end{enumerate}
このとき次が成り立つ．
\begin{enumerate}[label=(\roman*)]
\item 目的関数値は変化しない．
\item 元問題~\eqref{eq:lp}に対する双対実行可能性は保たれる．
\item 更新後の基底解も $M$ のアフィン関数であり，十分大きなすべての $M$ で $l\le x(M)\le u$ を満たす．
\item $x_j^1\neq0$ なる非基底変数の個数はちょうど $1$ 減る．
\end{enumerate}
\end{lemma}

\begin{proof}
(i)：移動による目的関数値の変化は $c_j(-x_j^1t)+c_B^\top(x_j^1t\,\alpha_{\cdot j})=-x_j^1t\,(c_j-c_B^\top A_B^{-1}A_j)=-x_j^1t\,\bar c_j=0$ である．

(ii)：(A)では基底が変わらないので被約費用は不変であり，$j$ の状態のみが変わるが，$\bar c_j=0$ は状態 $L,U,Z$ のいずれの条件も満たす．(B)では，タブロー更新公式により他の非基底変数 $k$ の被約費用は $\bar c_k^{\mathrm{new}}=\bar c_k-(\bar c_j/\alpha_{rj})\alpha_{rk}=\bar c_k$ と不変であり，脱退変数の被約費用は $\bar c_{\beta(r)}^{\mathrm{new}}=-\bar c_j/\alpha_{rj}=0$ となるから，$\beta(r)$ をどちらの境界に置いても符号条件を満たす．

(iii)：$t^\ast$ は $M$ のアフィン関数であるから，更新後の各成分もアフィン関数である．仮定より $x(M)$ は十分大きな $M$ で真の有限境界を満たすから，各 $t_i\succeq0$ であり，したがって $0\preceq t^\ast\preceq M$．非基底変数 $j$ は $x_j^1M$ と $0$ の間にとどまり，これは $j$ の上下限の範囲内である．移動を妨げうる基底変数 $i$ については $t^\ast\preceq t_i$ より境界までの余裕が $\succeq0$ に保たれ，その他の基底変数は非有界な側へ動くか動かない．(B)で脱退する $\beta(r)$ はちょうど有限境界上にある．他の非基底変数は変化しない．$\succeq0$ は十分大きな $M$ での数値的な非負性と一致する．

(iv)：(A)では $j$ の非基底値が $0$ となり $x_j^1=0$ となる．(B)では $j$ は基底に入り，代わって非基底となる $\beta(r)$ は有限境界に置かれる($x_{\beta(r)}^1=0$)．他の非基底変数の状態は変わらない．
\end{proof}

補題~\ref{lem:cleanup}を，$x_j^1\neq0$ なる非基底変数がなくなるまで繰り返し適用する．(iv)により，最終状態 $(B^\ast,\eta^\ast)$ における該当変数の個数を $K$ とすれば，ちょうど $K$ 回で終了する．得られた基底 $(\tilde B,\tilde\eta)$ では $x_N^1=0$ であるから，非基底値 $x_N=x_N^0$ は $M$ に依存せず，したがって基底値 $x_B=A_{\tilde B}^{-1}(b-A_Nx_N^0)$ も $M$ に依存しない定数である．(iii)より，この定数ベクトル $x^{\ast\ast}$ は十分大きな $M$ で(したがって $M$ によらず)$l\le x^{\ast\ast}\le u$ を満たし，元問題~\eqref{eq:lp}に対して主実行可能である．また(ii)より双対実行可能であるから，$x^{\ast\ast}$ は元問題の最適\emph{基底}解であり，(i)より $c^\top x^{\ast\ast}=z(M)=z^0$ である(命題~\ref{prop:trichotomy}(iii)と整合する)．

\begin{remark}[状態 $Z$ の使用と，零列の場合]
\label{rem:state-F}
状態 $Z$ が現れるのは，コスト $0$ の自由変数の初期配置(式~\eqref{eq:init-status})と，補題~\ref{lem:cleanup}の(A)で自由変数 $j$ を値 $0$ に置く場合に限られる．主反復で脱退する変数は $L$ または $U$ に置かれるから，主反復中に状態 $Z$ の変数が新たに生じることはない．また補題~\ref{lem:cleanup}の(B)で脱退する $\beta(r)$ は真に有限な境界に到達した変数であるから，後処理で自由変数が脱退することはない．また，$\alpha_{\cdot j}=A_B^{-1}A_j=0$ の場合は，どの $t_i$ も定義されないので自動的に(A)となり，$x_B$ を変えずに $j$ を有限な側(または状態 $Z$)へ移すだけで済む．
\end{remark}

\begin{remark}[任意の行でピボットする後処理との比較]
$x_j^1\neq0$ なる $j$ を，$\alpha_{rj}\neq0$ なる\emph{任意の}行 $r$ で基底に入れ，$\beta(r)$ を有限な側へ固定する退化ピボットでも，補題~\ref{lem:cleanup}の(i)(ii)(iv)は成り立つ．しかしこの場合，$\beta(r)$ の値が境界へ強制的に移されるために主実行可能性が失われ，$x_N^1=0$ に達した後に双対単体法を改めて再開する必要が生じる．その反復回数は事前に評価できない．補題~\ref{lem:cleanup}は，比検定によって脱退行を選ぶことで主実行可能性を保ち，この再開を不要にしている．また，最終状態の基底解 $x(M)$ に具体的な数値の $M$(主実行可能となる最小の値)を代入しても最適解は得られるが，その値は一般に基底解ではなく，傾きの小さい行があれば $M$ が極端に大きくなって数値誤差を招く．補題~\ref{lem:cleanup}の手続きは $M$ を記号のまま扱い，最後には $M$ を含まない基底解を与えるため，この問題も生じない．
\end{remark}

\begin{remark}[クロスオーバー手続きとの関係]
\label{rem:crossover}
\emph{クロスオーバー}\cite{megiddo1991,bixby1994,andersen1996}は，内点法で得られた最適面の相対的内部の解から，目的関数値を保ったまま上下限の間にある変数を1つずつ上下限に移すか基底に取り込むかして最適基底解を構成する手続きであり，主問題の変数を動かす段階を primal push，双対問題の変数を動かす段階を dual push と呼ぶ．

補題~\ref{lem:cleanup}の操作は，このクロスオーバー手続きにおける primal push と同じ構造を持つ．実際，最終状態 $(B^\ast,\eta^\ast)$ の基底解は，元問題に対しては最適であるが，$x_j^1\neq0$ なる非基底変数が元問題の上下限上にないため，元問題の基底解(端点)ではない．このような $x_j^1\neq0$ なる非基底変数 $j$ は，元問題から見ればどの有限な上下限にも置かれていない非基底変数(いわゆる superbasic 変数)であり，$z^1=0$ よりその被約費用は $0$ である．primal push は，このような変数を1つずつ上下限へ向けて動かし，途中で基底変数が先に上下限に達すればそれと入れ替えるピボットを行う．被約費用が $0$ であることから目的関数値と主・双対の実行可能性が保たれ，1回の操作で該当する変数がちょうど1個減るという性質(補題~\ref{lem:cleanup}(i)--(iv))も共通である．Megiddo\cite{megiddo1991}は，主・双対の最適解の組から高々 $n$ 回のピボットで最適基底が得られることをこの種の議論で示している．補題~\ref{lem:cleanup}は，この primal push を，移動量と基底解が $M$ のアフィン関数となる記号的な設定に適用し，比較を辞書式順序 $\succ$ で行うものである．なお，第\ref{sec:dual-view}節の双対性のもとでは，これは双対問題の側で，値 $0$ で基底に残った人工変数を最適性を保って追い出す操作，すなわちクロスオーバーの dual push にあたる．
\end{remark}

\subsection{非有界境界への非復帰と手法の解釈}
\label{sec:no-return}

反復の途中でひとたび $x_N^1=0$(非基底変数がすべて真に有限な上下限に置かれた状態)が達成されれば，以後の反復で非有界境界が非基底変数として再び現れることはない．この性質の核心は，有限な実数である $x_{B,r}$ が非有界な境界を「逸脱」することは決してない，という事実にある．

\begin{proposition}[非有界境界への非基底変数の非復帰]
\label{prop:no-return}
記号的人工上下限法(Step~2の(a$'$)(b$'$)(c)(d))による組合せ的状態遷移列 $(B^{(0)},\eta^{(0)})\to(B^{(1)},\eta^{(1)})\to\cdots$ を考える．ある $k_0\ge0$ で $(B^{(k_0)},\eta^{(k_0)})$ の非基底変数がすべて $x_j^1=0$(すなわち真に有限な上下限に置かれている)ならば，すべての $k\ge k_0$ で同じことが成り立つ．
\end{proposition}

\begin{proof}
$k\ge k_0$ に関する帰納法で示す．$k=k_0$ では仮定により成立する．ある $k\ge k_0$ で $(B^{(k)},\eta^{(k)})$ の非基底変数がすべて $x_j^1=0$ であると仮定し，$(B^{(k)},\eta^{(k)})\to(B^{(k+1)},\eta^{(k+1)})$ の1回の反復を考える．

まず，補題~\ref{lem:affine}において $x_N^1=0$ であるから $x_N(M)\equiv x_N^0$ であり，したがって $x_B^1=-A_B^{-1}A_Nx_N^1=0$，すなわち $x_B(M)\equiv x_B^0$ は $M$ に依存しない定数である．

各行 $i$ について，$\beta(i)$ が非有界な側を持つ場合(たとえば $l_{\beta(i)}=-\infty$)，対応する逸脱量 $v_i^-(M)=\hat l_{\beta(i)}(M)-x_{B,i}(M)=(-M)-x_{B,i}^0$ は傾き $-1$ を持ち，$M\to\infty$ で $-\infty$ に発散するから，いかなる $M^\dagger$ に対しても $M\ge M^\dagger$ で $v_i^-\succ0$ となることはない．一方，$\beta(i)$ の真に有限な側に対応する逸脱量は，$x_{B,i}(M)=x_{B,i}^0$ が定数であることと合わせて，やはり $M$ に依存しない定数である($u_{\beta(i)}=+\infty$ の場合も対称に同様)．したがって，脱退行 $r$ の逸脱量 $w_r(M)=w_r^1M+w_r^0$ は傾き $w_r^1=0$ の定数(通常の実数)である．

(i) \textbf{脱退変数が真に有限な境界に固定されること}：$w_r(M)$ が定数であることから，$r$ は必ず $\beta(r)$ の真に有限な側の逸脱によって選ばれる(非有界側の逸脱量は上で見た通り傾き $-1$ で発散し，$\succ0$ になり得ない)．Step~2(d)のピボットにより，$\beta(r)$ はその真に有限な境界に固定されて非基底化する．

(ii) \textbf{結論}：ピボットで基底化する加入変数 $q$ は非基底集合から除かれ，(i)によりピボットで非基底化する $\beta(r)$ は真に有限な境界に固定され，その他の非基底変数はこの反復によって状態を変えない．したがって $(B^{(k+1)},\eta^{(k+1)})$ の非基底変数もすべて $x_j^1=0$ である．
\end{proof}

\begin{remark}[吸収境界としての $x_N^1=0$ と実装上の帰結]
\label{rem:absorbing}
命題~\ref{prop:no-return}の証明から，$x_N^1=0$ に達した時点以降は，逸脱量がすべて $M$ に依存しない定数となり，Step~2の判定(主実行可能性の判定，脱退行の選択，比検定)は真の上下限 $l,u$ に関する第\ref{sec:dual-simplex}節の双対単体法の判定と完全に一致する．すなわち $x_N^1=0$ への到達は，以後の挙動を古典的双対単体法に一致させる吸収境界(absorbing boundary)として機能する．
\end{remark}

\begin{remark}[$z^1=0$ 到達後の反復について]
\label{rem:z1zero}
現在の状態における $z(M)$ の傾き $z^1=\sum_{j\in N}x_j^1\bar c_j$ は，双対実行可能性より各項が非正であり，$-z^1$ は元問題~\eqref{eq:lp}に対する双対の非実行可能性(非有界側に置かれた非基底変数の被約費用の絶対値の和)にあたる．初期状態では $z^1=-\sum_{j\in S}|c_j|$ である．双対単体法の各反復は十分大きなすべての $M$ で目的関数値を減少させないから，$(z^1,z^0)$ は辞書式に非減少であり，とくに $z^1$ は単調非減少で，一度 $0$ に達すれば以後 $0$ のままである．この意味で，記号的人工上下限法はおおむね $z^1<0$ の間は双対のフェーズ1に，$z^1=0$ に達して以降はフェーズ2に相当し，$S=\emptyset$ ならば初期状態ですでに後者にある．ただし，フェーズの正確な区切りは $z^1$ の符号ではなく第\ref{sec:two-phase}節の局面A・Bで与えられ(注~\ref{rem:not-delta})，反復列が古典的双対単体法と完全に一致するのは $x_N^1=0$ に達して以降である(注~\ref{rem:absorbing})．
\end{remark}

\begin{remark}[保証付きクラッシュ手続きとしての解釈]
双対実行可能性の条件は被約費用の符号のみで決まり $M$ に依存しないから，Step~2の反復は当初から一貫して元問題~\eqref{eq:lp}に対しても双対実行可能である．Step~2が実際に解消しているのは，非基底変数の一部が人工的な $\pm M$ に置かれているという一点($x_N^1\neq0$)に過ぎない．この観点に立てば，Step~2(補題~\ref{lem:cleanup}の後処理を含む)は，元問題に対して双対実行可能かつ非基底変数がすべて有限境界に置かれた開始基底を得るための\emph{クラッシュ手続き}とみなせる．第\ref{sec:difficulty}節の古典的なクラッシュ手続きがヒューリスティックで実行可能性の保証を持たないのに対し，この手続きは巡回防止規則(第\ref{sec:anticycling}節)のもとで\emph{必ず}有限回で $x_N^1=0$ に到達し(または非有界性・実行不可能性を検出し)，命題~\ref{prop:no-return}により一旦到達すれば後戻りしない．
\end{remark}

\begin{remark}[コストシフト法との比較]
双対単体法の開始時に広く用いられる技法に\emph{コストシフト法}(cost shifting)\cite{maros2003}がある．これは，双対実行可能性の条件に違反する非基底変数のコスト $c_j$ を人工的な値に一時的に置き換えて基底を\emph{見かけ上}双対実行可能にし，この人工目的関数のもとで双対単体法を実行したのち，コストを真の値へ戻しながら追加のピボットで双対実行可能性を回復する2段階の手続きである．

双対問題の側から見ると，コストシフト法と本稿の $M$ による有界化は，いずれも違反している双対制約 $\bar c_j\le0$ または $\bar c_j\ge0$ を一時的に緩和する操作である．両者の違いは，コストシフト法が双対制約の右辺 $c_j$ そのものを動かして\emph{ペナルティなしに}緩和し，後で元に戻すのに対し，本稿の有界化は違反量を人工変数として残したまま\emph{係数 $M$ のペナルティ付きで}緩和する(後述の第\ref{sec:dual-view}節)点にある．主問題の側から見れば，本稿は目的関数を人工化せず，最初から最後まで真の $c^\top x$ を用いる．ペナルティにより双対非実行可能性の解消が目的関数に組み込まれるため，次の2点で利点が生じる．第一に，コストシフト法ではシフトを戻す段階の追加ピボット数を一般には事前に特徴づけられないのに対し，本稿の後処理は目的関数値を変えず，主・双対の実行可能性を保ったまま高々 $K$ 回のピボットで終わることが証明されている(補題~\ref{lem:cleanup})．第二に，コストシフト法ではシフトする変数と量をヒューリスティックに決めるのに対し，本稿で無限側への配置を要する変数の集合 $S$ はデータから一意に定まり，さらに元問題の3通りの場合を判別する厳密な基準(命題~\ref{prop:trichotomy})が同じ枠組みから得られる．
\end{remark}

\subsection{巡回防止：Bland則の辞書式順序への拡張}
\label{sec:anticycling}

これまで，Step~2(a$'$)(b$'$)および比検定のいずれにおいても，同順位の候補の処理は「添字の小さい方を優先する」といった規則で決定的に定めるとするにとどめ，これだけでは一般に巡回(同一の基底を繰り返し訪れること)を排除できない点を留保してきた．古典的な上下限制約付き双対単体法において巡回を防ぐ標準的な方法は，Bland則(添字最小規則)\cite{bland1977}そのものを主選択規則として用いるか，あるいはDantzig則・最急辺規則・Devex則といった任意の主選択規則と両立させる\emph{辞書式規則}(lexicographic rule)\cite{dantzig1955}である．双対単体法における辞書式規則は，費用 $c$ を無限小 $\epsilon=(\epsilon_1,\epsilon_2,\dots)$，$\epsilon_1\gg\epsilon_2\gg\cdots\gg0$，で摂動させた場合の被約費用を辞書式に比較して比検定(Step~2(c))の同順位を解消するものである．巡回の原因は双対退化(比検定での比 $0$ の同順位)であるから，摂動が必要なのは比検定の側だけであり，脱退行の選択(Step~2(b))の同順位は任意の決定的な規則で解消してよい．

本稿の設定では，この辞書式規則は $M$ に関する辞書式順序 $\succ$ と干渉しない．比検定で比較される比 $\hat c_j/|\hat\alpha_j|$ は $M$ に依存せず，摂動後の被約費用もまた $M$ に依存しないから，比検定の同順位は $\epsilon$ に関する辞書式比較だけで解消できる．一方，$M$ が現れる判定((a$'$)(b$'$)の逸脱量の比較)は $M$ に関する $\succ$ だけで行い，脱退行の同順位は添字最小などの規則で解消すればよい．すなわち，$M$ と $\epsilon$ を連結した辞書式順序を用意する必要はない．

\begin{proposition}[巡回防止]
比検定の同順位を上記の費用摂動による辞書式規則で解消し，その他の同順位を任意の決定的な規則で解消するものとする．このとき，記号的人工上下限法の組合せ的な反復は同一の状態 $(B,\eta)$ を二度訪れず，有限回で停止する．
\end{proposition}

\begin{proof}
まず状態 $Z$ の変数を扱う．状態 $Z$ の変数のコストは摂動しない．状態 $Z$ の変数が加入可能なときは双対ステップ長 $\theta=0$ で基底化するから(注~\ref{rem:Z-invariant})，摂動後も被約費用は不変であり，状態 $Z$ の変数の被約費用は摂動後の問題でもちょうど $0$ に保たれる．このピボットで状態 $Z$ の非基底変数は1個減り，主反復中に状態 $Z$ の変数が新たに生じることはない(注~\ref{rem:state-F})．ゆえにこの種のピボットは高々初期の状態 $Z$ の変数の個数回しか起こらない．以下，それ以外のピボットを考える．

摂動後の問題では，固定変数と状態 $Z$ の変数を除く非基底変数の被約費用はすべて $\epsilon$ に関して辞書式に非零であり，この性質が反復を通じて保たれることは古典的な辞書式双対単体法の標準的な事実である．したがって各反復の双対ステップ長 $\theta_q$ は $\epsilon$ に関して辞書式に正である．一方，脱退行の逸脱量は $w_r\succ0$ であり，目的関数値の変化は $\theta_q\,w_r(M)$ であるから，十分大きな $M$ と十分小さな $\epsilon$ に対して目的関数値は真に増加する．状態 $(B,\eta)$ は有限個であり，目的関数値は状態によって定まるから(状態が有限個なので $M$ の閾値も一様にとれる)，状態 $Z$ の変数の個数が一定である区間で同一の状態を二度訪れることはない．状態 $Z$ の変数の個数は単調非増加であるから，全体としても同一の状態を二度訪れず，反復は有限回で停止する．
\end{proof}

すなわち，巡回防止には古典的な辞書式規則を比検定の側にのみ適用すれば足り，$M$ に関する辞書式順序 $\succ$ はそのまま用いることができる．

\section{傾き問題と切片問題への分解}
\label{sec:two-phase}

第\ref{sec:M-infty}節以降，(a$'$)(b$'$)の判定では，アフィン関数 $f^1M+f^0$ を係数対 $(f^1,f^0)$ の辞書式順序 $\succ$ で比較してきた．本節では，主反復においてはこの2つの成分が同時に効く場面が本質的になく，反復が「傾き $f^1$ のみで比較する局面」と「傾きが固定されたまま切片 $f^0$ で比較する局面」にちょうど分かれることを示す．

\subsection{傾き問題}
\label{sec:slope}
各変数 $j$ に対し，上下限の傾きを
\[
  l_j^1 := \begin{cases} -1 & (l_j=-\infty)\\ 0 & (l_j>-\infty)\end{cases},\qquad
  u_j^1 := \begin{cases} 1 & (u_j=+\infty)\\ 0 & (u_j<+\infty)\end{cases}
\]
とおき，また $l_j^0$ を $l_j>-\infty$ なら $l_j$，$l_j=-\infty$ なら $0$ とし，$u_j^0$ も同様に定める(スラック変数は $l^1=u^1=l^0=u^0=0$)．すると式~\eqref{eq:trunc}は $\hat l_j(M)=l_j^0+l_j^1M$，$\hat u_j(M)=u_j^0+u_j^1M$ と書ける．したがって，第\ref{sec:init-basis}節のゼロ固定スラック変数 $s$ を含めて書いた問題~\eqref{eq:lpM}は
\begin{equation}
  \min\ c^\top x \quad\text{s.t.}\quad Ax+s=b,\ \ 0\le s\le 0,\ \ l^0+l^1 M\le x\le u^0+u^1 M
  \label{eq:lpM-slack}
\end{equation}
である．この右辺 $b$ と定数部分 $l^0,u^0$ を $0$ とし，$M$ の係数 $l^1,u^1$ のみを上下限として残した問題
\begin{equation}
  \min\ c^\top x^1 \quad\text{s.t.}\quad Ax^1+s=0,\ \ 0\le s\le 0,\ \ l^1\le x^1\le u^1
  \label{eq:slope}
\end{equation}
を考え，これを\emph{傾き問題}と呼ぶ．変数を $x^1$ と書くのは，後の補題~\ref{lem:basic-slope}で見るように，その基底解がちょうど補題~\ref{lem:affine}の傾き $x^1$ に一致するからである．\eqref{eq:lpM-slack}，\eqref{eq:slope}のいずれにおいても $s$ は変数として残す．アルゴリズムの組合せ的状態 $(B,\eta)$ は $(x,s)$ の添字の上で定義され，基底 $B$ はスラック変数を含みうるからである．また $0\le s\le0$ は上下限であって，主実行可能でない基底解では基底に入った $s_i$ が $0$ 以外の値をとりうる．

傾き問題それ自体は新しいものではなく，双対単体法のフェーズ1として知られる，双対非実行可能性の総和を最小化する補助問題\cite{fourer1994,kostina2002,maros2003pl,koberstein2005,koberstein2007}に一致する．実際，Fourer\cite{fourer1994}の補助問題は，非有界な側の上下限をそれぞれ $-1,+1$，それ以外の上下限と右辺を $0$ とした問題であり，その上下限は $l^1,u^1$ の定義そのものである(Koberstein\cite{koberstein2005}は両側有限な変数を補助問題から除いているが，それらは傾き問題では $[0,0]$ に固定されるから同値である)．これらの文献では，補助問題は双対非実行可能性の総和の最小化として直接導かれ，人工上下限法\cite{koberstein2005}とは別個のフェーズ1の手法として扱われている．本節の導出は，この補助問題が，人工上下限法の問題~\eqref{eq:lpM}の $M$ の係数(傾き)を取り出したものとして現れることを示し，両者を結びつけるものである．

傾き問題は元問題の後退錐を $\|\cdot\|_\infty$ 球で切った問題であり，$x^1=0$ でつねに実行可能である．実際，元問題~\eqref{eq:lp}(前処理後)の実行可能領域を $F := \{\,x:\ Ax=b,\ l\le x\le u\,\}$ とし，
\[
  K_j :=
  \begin{cases}
    \{0\} & (\text{両側有限})\\
    [0,+\infty) & (\text{下限のみ有限})\\
    (-\infty,0] & (\text{上限のみ有限})\\
    \R & (\text{自由変数})
  \end{cases}
  ,\qquad
  C \ :=\ \{\,d:\ Ad=0,\ d_j\in K_j\ (j=1,\dots,n)\,\}
\]
とおく．$C$ は $F$ の右辺と有限な上下限を $0$ に置き換えた錐であり，$F\neq\emptyset$ のとき $F$ の後退錐 $\mathrm{rec}(F)$ に一致する．$[l_j^1,u_j^1]=K_j\cap[-1,1]$ であり，$s=0$ より $Ax^1+s=0$ は $Ax^1=0$ と同値であるから，\eqref{eq:slope}の実行可能領域は $C\cap\{\,d:\|d\|_\infty\le1\,\}$ である．\eqref{eq:lpM}において $x=Mx^1+x^0$ と書き $M$ で割って $M\to\infty$ とすれば\eqref{eq:slope}が得られるから，\eqref{eq:slope}は\eqref{eq:lpM}の $M\to\infty$ での「傾き」を取り出した問題にあたる．$F\neq\emptyset$ のとき「元問題が非有界 $\iff$ $c^\top d<0$ なる $d\in\mathrm{rec}(F)$ が存在する」ことはよく知られており\cite{bertsimas1997}，これは命題~\ref{prop:trichotomy}(ii)(iii)の判別 $z^1<0$ / $z^1=0$ と整合する．

\begin{lemma}[\eqref{eq:lpM-slack}と\eqref{eq:slope}の基底解の関係]
\label{lem:basic-slope}
組合せ的状態 $(B,\eta)$ を固定し，この状態に対する\eqref{eq:lpM-slack}の基底解を $x(M)=x^0+Mx^1$ と書く(補題~\ref{lem:affine})．このとき，傾き $x^1$ は同じ状態に対する\eqref{eq:slope}の基底解に一致し，切片は $x^0=x(0)$ である(いずれも $(B,\eta)$ から一意に定まる)．
\end{lemma}

\begin{proof}
\eqref{eq:lpM-slack}と\eqref{eq:slope}は制約行列 $[\,A\mid I\,]$ を共有するから，同じ $(B,\eta)$ が両方で基底解を定める．上下限はそれぞれ $l^0+l^1 M,\,u^0+u^1 M$ と $l^1,u^1$ である．

\eqref{eq:slope}の基底解を $\xi=(\xi_N,\xi_B)$ とおく．

非基底部分：$\eta(j)=L$ ならば $x_j(M)=l_j^0+l_j^1M$，$\xi_j=l_j^1$ である．$\eta(j)=U$ ならば $x_j(M)=u_j^0+u_j^1M$，$\xi_j=u_j^1$ である．$\eta(j)=Z$ ならば $x_j(M)=\xi_j=0$ である．したがって $x_N(M)=x_N^0+M\xi_N$ であり，$\xi_N=x_N^1$ である．実際，$l_j^1=-1$ となるのは $l_j=-\infty$ のとき，$u_j^1=1$ となるのは $u_j=+\infty$ のときに限るから，$\xi_j$ は補題~\ref{lem:affine}の $x_j^1$ の定義に一致する．

基底部分：\eqref{eq:lpM-slack}の等式制約の右辺は $b$，\eqref{eq:slope}の等式制約 $Ax^1+s=0$ の右辺は $0$ であるから，
\[
  x_B(M) \ =\ A_B^{-1}\bigl(b-A_Nx_N^0\bigr) + M\,A_B^{-1}\bigl(0-A_N\xi_N\bigr) \ =\ x_B^0 + M \xi_B
\]
であり，$\xi_B=-A_B^{-1}A_Nx_N^1=x_B^1$ である．以上より $\xi=x^1$ であり，$M=0$ とおけば $x^0=x(0)$ である．
\end{proof}

すなわち，$(B,\eta)$ を固定すると基底解は(右辺，上下限)の線型関数であり，\eqref{eq:lpM-slack}のデータは $(b,l^0,u^0)+M(0,l^1,u^1)$ と分解されるから，その $M$ の係数部分 $(0,l^1,u^1)$ をデータとする問題\eqref{eq:slope}の基底解が $x(M)$ の傾きとなる．したがって
\begin{itemize}
\item \eqref{eq:lpM}における逸脱量 $v_i^\pm=v_i^{\pm,1} M+v_i^{\pm,0}$ の傾き $v_i^{\pm,1}$ は，\eqref{eq:slope}における行 $i$ の逸脱量に等しい．
\item 被約費用・比 $\hat c_j/|\hat\alpha_j|$ はコスト $c$ と基底 $B$ のみで定まるから，両問題で共通である．
\item $z(M)=z^0+z^1M$ の傾き $z^1=c^\top x^1$ は，\eqref{eq:slope}の基底解の目的関数値に等しい．
\end{itemize}

\subsection{2段階分解}
\label{sec:two-phase-prop}

\begin{proposition}[2段階分解]
\label{prop:two-phase}
記号的人工上下限法の組合せ的状態遷移を考え，状態 $(B,\eta)$ が
\[
  \text{局面A}:\ \exists i,\ v_i^{-,1}>0\ \text{または}\ v_i^{+,1}>0,\qquad
  \text{局面B}:\ \forall i,\ v_i^{-,1}\le0\ \text{かつ}\ v_i^{+,1}\le0
\]
のいずれにあるかで場合分けする．
\begin{enumerate}[label=(\roman*)]
\item 局面Aでは，脱退行の選択を傾き $w_i^1$ のみで行い(傾きが最大の行どうしの同点は任意の決定的規則で解消)，選ばれた脱退行 $r$ の逸脱量を $w_r=w_r^1M+w_r^0$ とする(すなわち $w_r^1$ は $v_r^{-,1},v_r^{+,1}$ のうち正の方である．$v_r^{-,1}+v_r^{+,1}=l_{\beta(r)}^1-u_{\beta(r)}^1\le0$ より，両者が同時に正になることはない)．このとき，$\succ$ の第2成分を一切用いなくても，各反復は十分大きな $M$ に対する\eqref{eq:lpM}の双対単体法の反復として正当である．この反復はちょうど\eqref{eq:slope}に対する双対単体法であり，$\mathrm{Eligible}=\emptyset$ が生じることはない．局面Aは有限回で終了し，終了時の $z^1$ は\eqref{eq:slope}の最適値に等しい．
\item 状態がひとたび局面Bに入ると，以後の反復ですべての変数の値と上下限の傾き，したがってすべての $v_i^{\pm,1}$ および $z^1$ は変化せず，局面Aに戻ることはない．
\end{enumerate}
\end{proposition}

\begin{proof}
(i)：局面Aで選ばれる行 $r$ は $w_r^1>0$ を満たすから $w_r\succ0$，すなわち $r\in V_\infty$ である．双対単体法では，逸脱している行であればどれを脱退行に選んでも双対実行可能性は保たれ，双対目的関数は減少しないから，(b$'$)で $\succ$ の最大元の代わりにこの $r$ を選んでも，十分大きな $M$ に対する\eqref{eq:lpM}の双対単体法の反復として正当である．比検定は $M$ に依存しない．以上の判定はすべて\eqref{eq:slope}の量のみで行われるから，この反復は\eqref{eq:slope}に対する双対単体法そのものである．\eqref{eq:slope}は $x^1=0$ で実行可能であるから，その実行不可能性の証拠となる $\mathrm{Eligible}=\emptyset$ は起こらない．巡回防止は第\ref{sec:anticycling}節と同じ議論(\eqref{eq:slope}の目的関数値 $z^1$ が $\epsilon$ に関して辞書式に真に増加する)により従い，終了時には\eqref{eq:slope}の主実行可能性，すなわちすべての $v_i^{\pm,1}\le0$ が成り立つ．

(ii)：局面Bで選ばれる行は $w_r^1=0$，$w_r^0>0$ を満たす．ピボットにおける主ステップ長は $w_r/|\hat\alpha_q|$ であり，その傾きは $0$ であるから，基底変数の傾き $x_B^1$ も加入変数 $q$ の傾き $x_q^1$ も変わらない．脱退変数 $\beta(r)$ は逸脱していた側の境界に固定されるが，$w_r^1=0$ よりその境界の傾きは $\beta(r)$ の値の傾きに等しい．したがってすべての変数の値の傾きは不変であり，上下限の傾きはもとより不変であるから，各 $v_i^{\pm,1}$ と $z^1=c^\top(\text{傾きベクトル})$ も不変である．加入変数 $q$ については，その傾き $x_q^1$ が $l_q^1$ または $u_q^1$(状態 $Z$ なら $0$)に等しいから，新たな行の傾き $l_q^1-x_q^1$，$x_q^1-u_q^1$ はいずれも $\le0$ である．ゆえに局面Bは保たれる．
\end{proof}

\begin{corollary}[局面Aの終了時点で得られる判別]
\label{cor:phaseA}
局面Aの終了時の $z^1$(傾き問題~\eqref{eq:slope}の最適値)について，次が成り立つ．
\begin{enumerate}[label=(\roman*)]
\item $z^1<0$ ならば，元問題~\eqref{eq:lp}は非有界であるか実行不可能であり，有限な最適値を持たない．
\item $z^1=0$ ならば，元問題~\eqref{eq:lp}は有限な最適値を持つか実行不可能であり，非有界ではない．
\end{enumerate}
\end{corollary}

\begin{proof}
命題~\ref{prop:two-phase}(i)より，$z^1$ は傾き問題の最適値であり，第\ref{sec:slope}節で見たようにその実行可能領域は $C\cap\{d:\|d\|_\infty\le1\}$ である．$C$ は錐であるから，$z^1<0$ であることは $c^\top d<0$ なる $d\in C$ が存在することと同値である．$F=\emptyset$ ならば主張は自明であるから，$F\neq\emptyset$ とする．このとき $C=\mathrm{rec}(F)$ である．(i)：$c^\top d<0$ なる $d\in\mathrm{rec}(F)$ と $x\in F$ をとれば，$x+td\in F$ かつ $c^\top(x+td)\to-\infty\ (t\to\infty)$ であるから非有界である．(ii)：すべての $d\in\mathrm{rec}(F)$ で $c^\top d\ge0$ である．空でない多面体上の線型関数は，後退錐上で非負であれば下に有界であり，最小値を達成するから，有限な最適値を持つ．
\end{proof}

すなわち局面Aは，元問題が有限な最適値を持ちうるかどうか(双対問題の側から見れば，元の双対問題が実行可能かどうか．第\ref{sec:dual-two-phase}節)を判定する．一方，元問題が実行可能かどうかは局面Aだけでは定まらない．$z^1=0$ であっても元問題が実行不可能な場合はあり，$z^1<0$ の場合も同様である(注~\ref{rem:not-delta}の例)．この区別は局面Bで行われ(命題~\ref{prop:trichotomy}(i))，局面Bを通じて $z^1$ は変わらないから(命題~\ref{prop:two-phase}(ii))，局面Aの判別は最終的な判別と矛盾しない．とくに，元問題が実行可能であると別途わかっている場合には，非有界性は局面Aの終了時点で確定し，局面Bを実行する必要はない．

\subsection{切片問題}
\label{sec:intercept}
命題~\ref{prop:two-phase}(ii)により，局面Bではすべての変数の値の傾きが一定である．すなわち傾き $x^1=(x_N^1,x_B^1)$ は局面Bを通じて一定である．局面Aの終了時点で $x^1$ は\eqref{eq:slope}の実行可能解であるから，$Ax^1=0$ かつ $l^1\le x^1\le u^1$ である．この $x^1$ を固定し，$x=x^0+Mx^1$ と書いて，十分大きな $M$ に対する\eqref{eq:lpM}の制約を $x^0$ に関する条件に書き直すと，問題
\begin{equation}
  \min\ c^\top x^0 \quad\text{s.t.}\quad Ax^0+s=b,\ \ 0\le s\le 0,\ \ l^B\le x^0\le u^B
  \label{eq:intercept}
\end{equation}
\[
  l^B_j :=
  \begin{cases}
    -\infty & (x_j^1>l_j^1)\\
    l_j & (x_j^1=l_j^1=0)\\
    0 & (x_j^1=l_j^1=-1)
  \end{cases}
  ,\qquad
  u^B_j :=
  \begin{cases}
    +\infty & (x_j^1<u_j^1)\\
    u_j & (x_j^1=u_j^1=0)\\
    0 & (x_j^1=u_j^1=1)
  \end{cases}
\]
を得る．これを\emph{切片問題}と呼ぶ．実際，$x_j^1>l_j^1$ ならば $x_j=x_j^0+Mx_j^1$ は十分大きな $M$ で下限 $\hat l_j(M)=l_j^0+l_j^1M$ を自動的に満たすから下限は消え，$x_j^1=l_j^1=-1$ ならば $-M\le x_j^0-M$ より $x_j^0\ge0$ が残り，$x_j^1=l_j^1=0$ ならば $l_j\le x_j^0$ がそのまま残る(上限も同様)．目的関数は $c^\top x=c^\top x^0+Mz^1$ と分解され，$z^1=c^\top x^1$ は局面Bを通じて一定である．\eqref{eq:intercept}は，元問題を方向 $x^1$ に $M$ だけずらしたときに十分大きな $M$ で実行可能であり続ける点の集合を実行可能領域とする問題である．

\begin{proposition}[局面Bと古典的双対単体法の一致]
\label{prop:phaseB}
局面Bにおける記号的人工上下限法の反復(Step~2の(a$'$)(b$'$)(c)(d))は，問題~\eqref{eq:intercept}に対する第\ref{sec:dual-simplex}節の古典的双対単体法の反復と，同じ脱退行選択規則・同順位処理のもとで反復ごとに一致する．とくに，$x^1=0$ ならば\eqref{eq:intercept}は元問題~\eqref{eq:lp}そのものであり，局面Bは元問題に対する古典的双対単体法に一致する．
\end{proposition}

\begin{proof}
組合せ的状態 $(B,\eta)$ を共有する2つの反復の各判定が一致することを示す．
\begin{itemize}
\item \textbf{非基底変数の位置}：非基底変数 $j$ の傾き $x_j^1$ は $l_j^1$ または $u_j^1$(状態 $Z$ なら $0$)に等しいから，$j$ は\eqref{eq:intercept}の有限な境界 $x_j^0\in\{l^B_j,u^B_j\}$ 上にある．状態 $Z$ の変数は $l_j^1=-1<0=x_j^1<1=u_j^1$ より\eqref{eq:intercept}でも自由変数であり，値 $0$ に置かれる．また基底部分は $x_B^0$ である(補題~\ref{lem:basic-slope})．
\item \textbf{双対実行可能性と比検定}：被約費用，$\hat c_j$，比 $\hat c_j/|\hat\alpha_j|$ はコスト $c$ と基底 $B$ のみで定まり，状態 $L,U,Z$ に対する符号条件も共通であるから，両者で一致する．
\item \textbf{逸脱行の判定と脱退行の選択}：局面Bではすべての $v_i^{\pm,1}\le0$ である．$v_i^{\pm,1}<0$ の側は，$\beta(i)$ の傾きがその側の境界の傾きから真に離れていること，すなわち\eqref{eq:intercept}でその側の境界が無限大であることと同値であり，どちらでも逸脱とみなされない．$v_i^{\pm,1}=0$ の側では，切片 $v_i^{\pm,0}$ がそのまま\eqref{eq:intercept}における逸脱量に等しい．したがって $V_\infty$ は\eqref{eq:intercept}の逸脱行の集合に一致し，$\succ$ による比較は切片の比較に帰着するから，脱退行の選択も一致する．
\item \textbf{実行不可能性の判定}：$\mathrm{Eligible}=\emptyset$ は，\eqref{eq:intercept}に対する古典的双対単体法の実行不可能性の判定と同一の条件である．
\end{itemize}
最後に，$x^1=0$ ならば $x_j^1>l_j^1$ は $l_j^1=-1$，すなわち $l_j=-\infty$ と同値であり，$x_j^1=l_j^1=0$ は $l_j>-\infty$ と同値であるから $l^B=l$ である．同様に $u^B=u$ であり，\eqref{eq:intercept}は\eqref{eq:lp}に一致する．
\end{proof}

\begin{remark}[注~\ref{rem:absorbing}との関係]
$x_N^1=0$ ならば $x_B^1=0$，したがって $x^1=0$ であるから，注~\ref{rem:absorbing}は命題~\ref{prop:phaseB}の $x^1=0$ の場合にあたる．一方，局面Bには，$z^1<0$ の場合や，$z^1=0$ でも被約費用 $0$ の非基底変数が $\pm M$ に残る場合に，$x^1\neq0$ のまま入る．このとき\eqref{eq:intercept}は元問題の上下限の一部を取り除き，人工境界に由来する境界 $0$ を加えた問題であり，補題~\ref{lem:cleanup}の後処理は $x^1$ を取り除いて元問題へ戻る操作と解釈できる．なお局面Bでの比較は切片どうしの比較のみであるから，命題~\ref{prop:phaseB}は元の辞書式比較による記号的人工上下限法についても成り立つ．
\end{remark}

\subsection{全体像：基底を受け渡しながら解く問題の連鎖}
\label{sec:chain}
命題~\ref{prop:two-phase}，\ref{prop:phaseB}により，記号的人工上下限法，したがって傾き・切片双対二段解法(第\ref{sec:summary}節)は，次の連鎖として理解できる．
\begin{center}
\begin{tabular}{llll}
\toprule
段階 & 解く問題 & 手法 & 開始基底\\
\midrule
局面A & 傾き問題~\eqref{eq:slope} & 双対単体法 & スラック基底(計算なしに双対実行可能)\\
局面B & 切片問題~\eqref{eq:intercept} & 双対単体法 & 局面Aの最終基底\\
後処理 & 元問題~\eqref{eq:lp} & primal push(補題~\ref{lem:cleanup}) & 局面Bの最終基底\\
\bottomrule
\end{tabular}
\end{center}
局面Bが実行不可能で停止すれば元問題は実行不可能，最適で停止し $z^1<0$ ならば元問題は非有界であり，いずれもそこで終了する．$z^1=0$ の場合，$x^1=0$ ならば切片問題は元問題そのものであるから後処理は不要で(命題~\ref{prop:phaseB})，$x^1\neq0$ ならば後処理で $x^1$ を取り除く．すなわち傾き・切片双対二段解法は，「2つの LP を双対単体法で順に解き，必要ならクロスオーバーで元問題の基底に移る」手続きに同値である．

基底の受け渡しが正当であるのは，3つの問題の制約行列 $A$ とコスト $c$ が共通であるため被約費用の符号条件(双対実行可能性)がそのまま引き継がれ，かつ局面Aの最終基底の非基底変数が切片問題の有限な境界上にある(命題~\ref{prop:phaseB}の証明)からである．後処理は目的関数値と主・双対の実行可能性を保つ(補題~\ref{lem:cleanup})．

ただし次の2点に注意する．第一に，切片問題はデータのみからは定まらず，局面Aで得られた最適基底解 $x^1$ に依存する．傾き問題の最適解が一意でなければ，どの最適解に到達したかによって切片問題は異なるから，これは固定された LP を順に解く手続きではなく，前段の解が次段の問題を定める連鎖である．第二に，局面Aの同値性は，傾きのみで比較する変種(命題~\ref{prop:two-phase}(i))では厳密であるが，元の辞書式比較による版では，傾きが同点の行を切片で選び分けることが，傾き問題に対する双対単体法の同順位処理の特定の選択にあたる．逆に局面Aで傾きの同点を任意に解消すると，十分大きな数値 $M$ での反復列との完全な一致(命題~\ref{prop:consistency})は一般に失われるが，双対実行可能性，巡回防止，および3通りの場合の判別はそのまま成り立つ．

\begin{remark}[局面Aは主単体法で置き換えてよいこと]
\label{rem:phaseA-primal}
連鎖において局面Aから局面Bへ受け渡されるのは，傾き問題~\eqref{eq:slope}の最適基底，すなわちスラック変数を含む状態 $(B,\eta)$ であって，\eqref{eq:slope}に対して主実行可能(局面Bの条件 $v_i^{\pm,1}\le0$)かつ\eqref{eq:lpM}に対して双対実行可能なものだけである．命題~\ref{prop:two-phase}(ii)，命題~\ref{prop:phaseB}および系~\ref{cor:phaseA}はこの性質のみを用いるから，その基底をどの手法で得るかは問わず，双対単体法の代わりに主単体法を用いてもよい．実際，スラック基底 $B_0$ のもとで各非基底変数を傾き $0$ の側に置けば(有限な側があればそこへ，自由変数は状態 $Z$ に)，基底解は $x^1=0$，$s=0$ であり，\eqref{eq:slope}の右辺が $0$ であるから，これは主実行可能な基底である．したがって主単体法はフェーズ1なしに出発でき，有限回で最適基底に到達する．その基底では $l_j^1<u_j^1$ なる非基底変数の被約費用は状態 $L,U,Z$ に応じた符号条件を満たす．\eqref{eq:slope}で $[0,0]$ に固定される両側有限な変数には符号条件が課されないが，その傾きは $0$ であるから，被約費用の符号に合わせて $\eta(j)$ を付け替えれば(注~\ref{rem:fixed}，第\ref{sec:known-two-phase}節の(1)と同じ操作)，$x^1$ を変えずに\eqref{eq:lpM}に対して双対実行可能となる．ただしこの場合，局面Aの反復はもはや\eqref{eq:lpM}に対する双対単体法の反復ではなく，傾き・切片双対二段解法を\eqref{eq:lpM}に対する単一の記号的な双対単体法(記号的人工上下限法)とみる見方は局面Bと後処理についてのみ成り立つ．また傾き問題の最適解は一意とは限らないから，到達する $x^1$，したがって切片問題は一般に双対単体法による場合と異なる．なお出発点 $x^1=0$ ではすべての基底変数が $0$ であり主退化が著しいから，いずれが効率的かは問題に依存し，本稿では評価しない．
\end{remark}

\begin{remark}[変数選択規則は分離によって本質的に変わらないこと]
\label{rem:pricing}
問題が傾き問題と切片問題に分離されるからといって，各問題に固有の変数選択規則が新たに得られるわけではない．最急辺規則の重み $\gamma_i=\sum_{j\in N}\alpha_{ij}^2$ も Devex規則の近似重みも，制約行列 $[\,A\mid I\,]$ と基底 $B$(およびピボットの履歴)のみから定まり，右辺や上下限に依存しない．3つの問題\eqref{eq:lpM-slack}，\eqref{eq:slope}，\eqref{eq:intercept}は制約行列を共有するから，同じ基底における重みは3つの問題で一致する．したがって「傾き問題に対する最急辺規則」は，元の問題の最急辺規則の重みで傾きの逸脱量 $w_i^1$ を正規化したもの，「切片問題に対する最急辺規則」は同じ重みで切片問題の逸脱量を正規化したものにほかならない．加入変数の比 $\hat c_j/|\hat\alpha_j|$ も $c$ と $B$ のみで定まるから同様である．重みは局面をまたいでそのまま引き継げ，局面の切り替えに再計算を要しないという実装上の利点はあるが，分離によって選択の質が改善するとは期待できない(Devex規則の基準を局面Bの開始時に取り直す余地はあるが，その効果は経験的に確かめる必要がある)．
\end{remark}

\begin{remark}[局面の区切りについて]
\label{rem:not-delta}
命題~\ref{prop:two-phase}の局面A・Bの区切りは，「$M$ が残っている間($x^1\neq0$)」とも「$z^1<0$ の間」とも異なる．
\begin{enumerate}[label=(\alph*)]
\item $M$ が残っていても $w_i^1=0$，$w_i^0>0$ の行はありうる．たとえば
\[
  \min\ x_1\quad\text{s.t.}\quad x_2=5,\ \ x_1\ \text{自由},\ \ 0\le x_2\le1
\]
では，初期状態で $x_1=-M$($x_1^1=-1$)であるが，行1の逸脱量は $v_1^+=5$(傾き $0$)である．第1成分だけで(a$'$)を判定すると $V_\infty=\emptyset$ かつ $z^1=-1<0$ となり，実行不可能な問題を「非有界」と誤判定する．
\item 局面Aの途中で $z^1=0$ となっても，双対退化なピボットにより局面Aが続くことがある．逆に局面Bでは $z^1$ が固定されるから，局面Aの終了時に $z^1<0$ であれば $z^1<0$ のまま局面Bが進み，実行不可能か非有界かは局面Bで判別される．双対のフェーズ1の実体は局面A，すなわち\eqref{eq:slope}を解く過程である．
\end{enumerate}
また補題~\ref{lem:cleanup}の後処理では，$t_i$ と $M$ の傾きが一致する場合や傾きの等しい $t_i$ どうしの比較で切片が必要であり，両成分を用いる辞書式比較が不可欠である．
\end{remark}

\subsection{既存の2段階の双対単体法との比較}
\label{sec:known-two-phase}

\paragraph{既存の方法．}
局面Aで解く傾き問題は，双対単体法のフェーズ1として知られる補助問題\cite{fourer1994,kostina2002,maros2003pl,koberstein2005,koberstein2007}と一致する(第\ref{sec:slope}節)．この補助問題を用いる既存の2段階の双対単体法(例えば文献\cite{koberstein2005}のAlgorithm~8)は，次のように述べられる．
\begin{enumerate}[label=(\arabic*)]
\item 両側有限な変数は，被約費用の符号に合わせて一方の境界に置く(dual feasibility correction)．これによりフェーズ1で扱う双対非実行可能性は，非有界な側を持つ変数に由来するものだけとなる．
\item 右辺を $0$ とし，非有界な側を持つ変数の上下限を，下限のみ有限な変数は $[0,1]$，上限のみ有限な変数は $[-1,0]$，自由変数は $[-1,1]$ に置き換えた補助問題を作る(両側有限な変数は除く)．この問題はすべての変数が有界であるから，任意の基底から出発して，最急辺規則や BFRT を備えた通常の双対単体法(フェーズ2のコード)でそのまま解ける．その最適値 $z_0$ の符号を反転したものは，元の双対問題の非実行可能性の総和の最小値である．
\item $z_0<0$ ならば元問題は双対実行不可能であり，停止する．この場合，元問題が非有界か実行不可能かは区別されず，その区別には主単体法などの別の手続きを要する．たとえば HiGHS(バージョン 1.15.1)の双対単体法は，この状態で停止すると，既定の設定では主単体法を改めて実行して両者を区別する\cite{huangfu2018}．
\item $z_0=0$ ならば，得られた基底は元問題に対して双対実行可能である．元の上下限と右辺に戻す．このとき補助問題で $\pm1$ の境界にあった非基底変数は被約費用が $0$ であるから，有限な側(自由変数なら値 $0$ の非基底状態)に置いてよい．そのうえで元問題に双対単体法(フェーズ2)を適用する．
\end{enumerate}
すなわち既存の方法は，補助問題によるフェーズ1と元問題に対するフェーズ2からなる2段階の方法であり，$M$ はどこにも現れない．人工上下限法は，これとは別個のフェーズ1の手法として扱われている\cite{koberstein2005}．

\paragraph{Algorithm~\ref{alg:slope-intercept}との違い．}
局面Aは(2)のフェーズ1と同じ問題を解く．両者の違いは，局面Aの終了時の $z^1$ と $x^1$ に応じて次のように現れる．
\begin{enumerate}[label=(\alph*)]
\item $z^1=0$ かつ $x^1=0$ の場合，切片問題は元問題そのものであり(命題~\ref{prop:phaseB})，両者は一致する．
\item $z^1=0$ かつ $x^1\neq0$ の場合，$z^1=c^\top x^1=\sum_{j\in N}\bar c_jx_j^1$ の各項は双対実行可能性により非正であるから，$x_j^1\neq0$ なる非基底変数(人工境界上の変数)はすべて $\bar c_j=0$ を満たす．既存の方法は(4)でこれらを有限な側へ置き直して $x^1=0$ とし，元問題のフェーズ2に進む．Algorithm~\ref{alg:slope-intercept}は，これらを人工境界に置いたまま切片問題を解き，最後に補題~\ref{lem:cleanup}の後処理で $x^1$ を取り除く．局面Bの出発時の基底と基底解 $x_B^0$ は両者で一致するが(前処理により，人工境界上の変数の切片の値 $l_j^0,u_j^0$ と置き直し先の有限な境界はいずれも $0$ である)，局面Bで解く問題は $x^1$ の台の上で上下限が異なり，反復と最終的な最適基底は一般に異なる．最適値はいずれも $z^0$ である．
\item $z^1<0$ の場合，既存の方法は(3)で非有界と実行不可能を区別せずに停止する．Algorithm~\ref{alg:slope-intercept}は局面Aの基底からそのまま切片問題を双対単体法で解き，この区別を双対単体法だけで行う(命題~\ref{prop:trichotomy})．我々の調べた範囲では，この扱いを述べた文献は見当たらない．
\end{enumerate}

\paragraph{統一的な見方．}
(b)の2つの方法は，\eqref{eq:lpM}の枠組みの中で統一的に理解できる．十分大きな $M$ に対する\eqref{eq:lpM}では，被約費用が $0$ の非基底変数は上下どちらの境界に置いても双対実行可能であり，その置き方は双対単体法にもともとある自由度である(BFRT におけるフリップや(1)の dual feasibility correction と同種の操作である)．人工境界上の変数をそのまま置いて局面Bに進めば，命題~\ref{prop:phaseB}により局面Bは切片問題に対する双対単体法となり，後処理を要する．これが Algorithm~\ref{alg:slope-intercept}である．局面の境界でこれらを反対側の有限な境界へフリップすれば(自由変数なら状態 $Z$ に置けば)，$x^1=0$ となり，命題~\ref{prop:no-return}と注~\ref{rem:absorbing}により局面Bは元問題に対する古典的双対単体法となって，後処理を要しない．これが既存の方法である．すなわち $z^1=0$ の場合，両者は同じ記号的人工上下限法を，双対退化な非基底変数の置き方だけを変えて実行したものであり，既存の方法は本稿の枠組みにフリップを1回加えることで導かれる．逆向きの導出は非対称であり，$M$ を持たない既存の枠組みの中からは，切片問題も後処理も自然には現れない．それらが現れるには，最適解が $x^0+Mx^1$ の形をとるという $M$ に関するパラメータ付けが必要である．また $z^1<0$ の場合には，人工境界に $\bar c_j\neq0$ の変数が残り，これをフリップすると双対実行可能性が失われるから，置き直しは適用できない．

\paragraph{新規性の範囲．}
以上より，傾き・切片双対二段解法は局面Aでは既存のフェーズ1と同じ問題を解くが，局面Bで切片問題を解く点で，アルゴリズムとしては既存の方法と異なる(本稿の貢献は第\ref{sec:contribution}節にまとめた)．(b)の場合に既存の置き直しと本稿の経路のどちらが効率的かは本稿では評価しておらず，理論的な優劣も定まらない．

\section{双対問題から見た解釈}
\label{sec:dual-view}

\subsection{双対問題に対する大$M$法}
\label{sec:dual-bigM}

ここまでの構成は，双対問題の側から見ると，元問題の双対問題に古典的な大$M$法を適用し，$M$ を記号的に扱ったものに他ならない．本節ではこの対応をまとめる．

非有界な側を持つ添字の集合を $J^-:=\{j:l_j=-\infty\}$，$J^+:=\{j:u_j=+\infty\}$ とおく．有界化した問題~\eqref{eq:lpM}を再掲すると
\begin{equation}
  \min\ c^\top x \quad \text{s.t.}\quad Ax=b,\ \hat l\le x\le \hat u
  \tag{\ref{eq:lpM}}
\end{equation}
であり，式~\eqref{eq:trunc}より $\hat l_j=-M\ (j\in J^-)$，$\hat u_j=M\ (j\in J^+)$，それ以外は $\hat l_j=l_j$，$\hat u_j=u_j$ である．この問題の双対問題は，下限・上限制約に対する双対変数を $\kappa,\nu\in\R^n$ として
\begin{align}
  \max\quad & b^\top y+\sum_{j\notin J^-} l_j\kappa_j-\sum_{j\notin J^+} u_j\nu_j\ -\ M\Bigl(\sum_{j\in J^-}\kappa_j+\sum_{j\in J^+}\nu_j\Bigr) \label{eq:dualM}\\
  \text{s.t.}\quad & A^\top y+\kappa-\nu=c,\quad \kappa,\nu\ge0 \notag
\end{align}
で与えられる(ゼロ固定スラック $s$ は主問題を変えないので，ここでは省いて考えてよい)．一方，元問題~\eqref{eq:lp}には非有界な側の上下限制約が存在しないから，その双対問題は\eqref{eq:dualM}に
\[
  \kappa_j=0\ \ (j\in J^-),\qquad \nu_j=0\ \ (j\in J^+)
\]
を課した(したがってペナルティ項が消えた)問題であり，$\bar c_j:=c_j-A_j^\top y$ に対する双対制約 $\bar c_j\le0\ (j\in J^-)$，$\bar c_j\ge0\ (j\in J^+)$ を持つ(自由変数では $\bar c_j=0$)．すなわち，$\kappa_j\ (j\in J^-)$，$\nu_j\ (j\in J^+)$ はこれらの双対制約の違反量を吸収する\emph{人工変数}であり，\eqref{eq:dualM}は元の双対問題に人工変数を導入して係数 $M$ のペナルティを課した大$M$法の問題そのものである．つまり，主問題の非有界な上下限を $\mp M$ で置き換えることは，双対問題の制約を係数 $M$ のペナルティで緩和することと双対な操作である．これは，主問題に対する大$M$法の双対問題が双対変数を $M$ で有界化した問題となるというよく知られた事実の，主と双対を入れ替えた形にあたる．

さらに，主問題に対する双対単体法は，双対問題に対する主単体法を主問題のタブロー上で実行したものである\cite{lemke1954,bertsimas1997}．実際，組合せ的状態 $(B,\eta)$ に対し，相補性から定まる基底双対解を
\[
  y^\top=c_B^\top A_B^{-1},\qquad
  \kappa_j=\bar c_j\ \ (j\in N,\ \eta(j)=L),\qquad
  \nu_j=-\bar c_j\ \ (j\in N,\ \eta(j)=U)
\]
(その他の成分は $0$)とおくと，等式制約 $A^\top y+\kappa-\nu=c$ は自動的に満たされ，$\kappa,\nu\ge0$ はちょうど第\ref{sec:dual-simplex}節の双対実行可能性の条件に一致する．このときの\eqref{eq:dualM}の目的関数値は $b^\top y+\sum_{j\in N}\bar c_jx_j(M)$ であり，第\ref{sec:M-infty}節で見た $z(M)=z^0+z^1M$ に等しく，そのペナルティ部分は
\[
  -z^1 \ =\ \sum_{\substack{j\in N\cap J^-\\ \eta(j)=L}}\kappa_j\ +\sum_{\substack{j\in N\cap J^+\\ \eta(j)=U}}\nu_j ,
\]
すなわち人工変数の値の総和(元の双対問題に対する非実行可能性)である．したがって，本稿のアルゴリズムは，双対問題~\eqref{eq:dualM}に対して，$M$ を記号的に扱う大$M$法を主単体法で実行したものと一致する．各構成要素は次のように対応する．

\begin{itemize}
\item \textbf{自明な初期基底}(第\ref{sec:init-basis}節)：$y=0$ では $\bar c=c$ であり，人工変数が正となるのはちょうど $j\in S$ に対してで，その値は $|c_j|$ である．大$M$法において，人工変数が制約の違反を吸収することで自明な初期基底が得られるのと同じ構造である．ただし人工変数が必要となるのは，すべての行ではなく，違反している双対制約 $j\in S$ に対してのみである．また人工変数の列を陽に追加する必要はなく，主問題の非基底変数を $\mp M$ に置くことがそれを暗に表している．
\item \textbf{非有界境界上の非基底変数}：$x_j^1\neq0$ なる非基底変数 $j$ は，人工変数 $\kappa_j$ または $\nu_j$(値 $|\bar c_j|$)が双対問題の基底に残っていることに対応する．
\item \textbf{辞書式比較 $\succ$}(第\ref{sec:M-infty}節)：係数対 $(z^1,z^0)$ の辞書式比較は，人工変数の総和(双対非実行可能性)の最小化を元の目的関数に優先させる辞書式最適化\cite{sherali1983}にあたり，$M$ を非アルキメデス的な無限大として扱う大$M$法\cite{cococcioni2021}を双対問題に適用したものとみなせる．$M$ を数値として固定すれば人工上下限法\cite{koberstein2007,huang2021}となる．$\succ$ の2つの成分と双対のフェーズ1・フェーズ2の対応は第\ref{sec:dual-two-phase}節で述べる．
\item \textbf{3通りの場合の判別}(命題~\ref{prop:trichotomy})：停止時に $z^1<0$ であることは，十分大きなすべての $M$ で人工変数が正のまま残る，すなわち元の双対問題が実行不可能であることに対応し，$F\neq\emptyset$ と合わせて元問題の非有界性が従う．$\mathrm{Eligible}=\emptyset$ による停止は，\eqref{eq:dualM}が非有界となる場合に対応する．これらは大$M$法の古典的な判定を双対問題に適用したものである．
\item \textbf{$M^\dagger$ の存在}(補題~\ref{lem:union})：ペナルティを課した双対制約の乗数は主変数 $x_j$ そのものであるから，$M\ge\|x\|_\infty$ ならば $x\in F_M$ となるという補題~\ref{lem:union}の議論は，ペナルティ係数が最適乗数の大きさを上回れば $L_1$ ペナルティが厳密になるという，厳密ペナルティの閾値の議論にあたる．
\item \textbf{後処理}(補題~\ref{lem:cleanup})：$z^1=0$ かつ $x_j^1\neq0$ なる $j$ は，値 $0$ で双対問題の基底に残った人工変数に対応し，補題~\ref{lem:cleanup}はこれを基底から追い出す操作にあたる．教科書的な手続きは非零要素を持つ任意の行でピボットするため双対問題の最適性(主問題の実行可能性)を失いうるが，補題~\ref{lem:cleanup}の主比検定はこれを保つように行を選ぶものであり，クロスオーバーの dual push にあたる(注~\ref{rem:crossover})．
\item \textbf{非有界境界への非復帰}(第\ref{sec:no-return}節)：$x_N^1=0$ への到達は，人工変数がすべて双対問題の基底から出たことに対応し，以後の反復は元の双対問題に対する主単体法，すなわち元問題に対する古典的双対単体法となる(注~\ref{rem:absorbing})．
\end{itemize}

\subsection{双対問題に対する2段階法}
\label{sec:dual-two-phase}
第\ref{sec:two-phase}節の分解を双対問題の側から見る．双対変数は引き続き $\kappa,\nu$ と書く．傾き問題~\eqref{eq:slope}の双対問題は
\begin{equation}
  \max\ -\Bigl(\sum_{j\in J^-}\kappa_j+\sum_{j\in J^+}\nu_j\Bigr)
  \quad\text{s.t.}\quad A^\top y+\kappa-\nu=c,\ \ \kappa,\nu\ge0
  \label{eq:dual-phase1}
\end{equation}
である($b=0$ および有限な上下限が $0$ であるため，目的関数には非有界な側に対応する双対変数のみが現れる)．これは\eqref{eq:dualM}からペナルティ項のみを残した問題，すなわち元の双対問題に人工変数 $\kappa_j\ (j\in J^-)$，$\nu_j\ (j\in J^+)$ を導入してその総和を最小化する，\emph{双対問題に対するフェーズ1}そのものである．その最適値は $z^1$ に等しい．

一方，切片問題の双対問題は
\begin{align*}
  \max\quad & b^\top y+\sum_{j} l^B_j\kappa_j-\sum_{j} u^B_j\nu_j\\
  \text{s.t.}\quad & A^\top y+\kappa-\nu=c,\ \ \kappa,\nu\ge0,\ \ \kappa_j=0\ (x_j^1>l_j^1),\ \ \nu_j=0\ (x_j^1<u_j^1)
\end{align*}
である．主問題に存在しない上下限には乗数が対応しないから，上下限が無限大の側の双対変数は $0$ に固定される．すなわち切片問題で上下限を取り除くことは，双対問題で対応する乗数を $0$ に固定することにあたる．

一方，局面Aの終了時の $x^1$ は傾き問題~\eqref{eq:slope}，すなわち\eqref{eq:dual-phase1}の主問題の最適解である．相補性定理により，主問題の最適解を1つ固定すれば，双対問題の実行可能解が最適であることは，その固定した最適解と相補的であることと同値である．したがって\eqref{eq:dual-phase1}の実行可能解 $(y,\kappa,\nu)$ が最適であることは，$x^1$ との相補性 $\kappa_j(x_j^1-l_j^1)=0$，$\nu_j(u_j^1-x_j^1)=0$，すなわち
\[
  \kappa_j=0\ \ (x_j^1>l_j^1),\qquad \nu_j=0\ \ (x_j^1<u_j^1)
\]
と同値である(スラック変数 $s$ は $l^1=u^1=x^1=0$ であるから条件を課さない)．これは切片問題の双対問題で $0$ に固定される乗数の条件と添字ごとに一致し，残りの制約 $A^\top y+\kappa-\nu=c$，$\kappa,\nu\ge0$ も共通である．したがって切片問題の双対問題の実行可能領域は，ちょうど\emph{双対フェーズ1の最適面}に一致する．また人工境界に由来する境界($x_j^1=l_j^1=-1$ なら $l^B_j=0$，$x_j^1=u_j^1=1$ なら $u^B_j=0$)に対応する人工変数は，この面の上で費用 $0$ の変数として残る(最適面上では人工変数の総和は $-z^1$ に固定されている)．ゆえに切片問題を解くことは，双対フェーズ1の最適面の上で元の双対目的関数を最大化すること，すなわち\emph{双対問題のフェーズ2}にあたる．切片問題で元問題の上下限の一部が消えることは，2段階法においてフェーズ1の後に被約費用が正の変数を除く(最適面に制限する)操作の双対版である．

以上により，記号的人工上下限法は双対問題に対する大$M$法であると同時に双対問題に対する2段階法でもあり，この対応は極限の目的関数値のレベルではなく反復のレベルで成り立つ．大$M$法が $M\to+\infty$ で2段階法に一致するという古典的事実\cite{chvatal1983,bertsimas1997}は通常目的関数値の比較として述べられるが，本稿の設定では，$\succ$ の第1成分と第2成分がそれぞれ局面A(フェーズ1)と局面B(フェーズ2)にちょうど割り当てられる．第\ref{sec:summary}節のアルゴリズムは，この対応に基づき，辞書式比較を用いずに2つの局面を順に実行する．

\section{傾き・切片双対二段解法：まとめ}
\label{sec:summary}

以上の構成要素をすべて統合し，一般の線型計画問題~\eqref{eq:lp}に対する\emph{傾き・切片双対二段解法}をAlgorithm~\ref{alg:slope-intercept}としてまとめる．名称の「双対」は，各局面が双対単体法であることと，全体が双対問題に対する2段階法(第\ref{sec:dual-two-phase}節)にあたることの両方を指す．第\ref{sec:M-infty}節の(a$'$)(b$'$)は，アフィン関数を係数対の辞書式順序 $\succ$ で比較する形で反復を与えたが，第\ref{sec:two-phase}節で見たように，この比較の第1成分(傾き)と第2成分(切片)は主反復の中で同時には効かない．そこでAlgorithm~\ref{alg:slope-intercept}では，主反復を辞書式比較によらず，傾き問題~\eqref{eq:slope}と切片問題~\eqref{eq:intercept}を順に解く2つの局面として実行する．入力の $A,b,c,l,u$ は前処理前の元のデータでよく，自由変数も特別な前処理を要さない．

Algorithm~\ref{alg:slope-intercept}は，前処理(第\ref{sec:shift-preprocess}節)ののち，次の2つの局面と，必要に応じて行う後処理からなる．
\begin{itemize}
\item \textbf{局面A(傾き問題)}：計算なしに得られる双対実行可能初期基底(第\ref{sec:init-basis}節)から出発し，傾き問題~\eqref{eq:slope}に対する双対単体法を実行する．保持するのは傾き問題の基底解 $x^1$ のみであり，切片 $x^0$ は保持しない．
\item \textbf{局面B(切片問題)}：局面Aの最終基底から，切片問題~\eqref{eq:intercept}に対する通常の実数値の双対単体法を実行する．停止時に，元問題が実行不可能か，非有界か，有限な最適値を持つかを判別する．
\item \textbf{後処理}：有限な最適値を持ち，人工境界に非基底変数が残っている場合($x_N^1\neq0$)に限り，補題~\ref{lem:cleanup}の primal push で $M$ を含まない最適基底解を構成する．
\end{itemize}
最後に平行移動の逆変換で元の座標系に戻す．比検定の同順位は第\ref{sec:anticycling}節の費用摂動による辞書式規則で解消する．局面A・Bで解く問題はいずれも通常の LP であるから，実装においては，最急辺規則・Devex規則による脱退行の選択や Bound Flipping Ratio Test といった双対単体法の標準的な技法を，$M$ に関する特別な扱いなしに各局面にそのまま適用できる．

\begin{center}
\refstepcounter{algorithm}
\textbf{Algorithm~\thealgorithm.} \textsc{SlopeInterceptDualTwoPhase}$(A,b,c,l,u)$ ――傾き・切片双対二段解法
\label{alg:slope-intercept}
\end{center}
\begin{algorithmic}[1]

\Statex \textbf{前処理}
\State 各 $j$ に対しシフト量 $t_j$ を計算し，$A,b,l,u \gets A,\ b-At,\ l-t,\ u-t$ と置き換える(自由変数は $t_j=0$) \Comment{第\ref{sec:shift-preprocess}節}
\State 各 $j$ について上下限の傾き $l_j^1,u_j^1$ を定める(スラック変数は $l^1=u^1=0$) \Comment{第\ref{sec:two-phase}節}

\Statex \textbf{局面A：傾き問題~\eqref{eq:slope}}
\State $B\gets\{n+1,\dots,n+m\}$(スラック添字)；各 $j=1,\dots,n$ について式~\eqref{eq:init-status}に従い $\eta(j)\gets L$ ($c_j>0$，または $c_j=0$ かつ $l_j>-\infty$)，$Z$ ($c_j=0$ かつ自由変数)，$U$ (それ以外) \Comment{計算なしに双対実行可能，命題~\ref{prop:dual-feasible-init}}
\State $x_N^1\gets$ 補題~\ref{lem:affine}の非基底の傾き；$x_B^1\gets -A_Nx_N^1$ \Comment{$A_B=I$．傾き問題の基底解 $x^1$，補題~\ref{lem:basic-slope}}
\Loop
  \State 各行 $i$ について $v_i^{-,1}\gets l_{\beta(i)}^1-x_{B,i}^1$，$v_i^{+,1}\gets x_{B,i}^1-u_{\beta(i)}^1$ \Comment{逸脱量の傾き}
  \State $V_A\gets\{\,i : v_i^{-,1}>0 \text{ または } v_i^{+,1}>0\,\}$
  \If{$V_A=\emptyset$}
    \State \textbf{break} \Comment{傾き問題の最適基底に到達．局面Bへ}
  \EndIf
  \State $w_i^1\gets\max(v_i^{-,1},v_i^{+,1})$ として，$r\gets\operatorname{arg\,max}_{i\in V_A} w_i^1/\sqrt{\gamma_i}$ \Comment{Dantzig則は $\gamma_i\equiv1$；同順位は任意の決定的規則}
  \State $\rho\gets+1$ ($v_r^{-,1}>0$ のとき)，$-1$ ($v_r^{+,1}>0$ のとき)；$\alpha^\top\gets e_r^\top A_B^{-1}A_N$；$\sigma_j,\hat\alpha_j,\hat c_j\gets\cdots$ \Comment{Step~2(c)}
  \State $\mathrm{Eligible}\gets\{j\in N : l_j<u_j,\ \rho\,\hat\alpha_j<0\}$ \Comment{両側有限な変数も候補に含める．空にならない}
  \State $q\gets\operatorname{arg\,min}_{j\in\mathrm{Eligible}}\hat c_j/|\hat\alpha_j|$ \Comment{状態 $Z$ の候補は比 $0$ で最優先．同順位は第\ref{sec:anticycling}節の規則}
  \State $\beta(r)\leftrightarrow q$ を交換するピボット；$B,A_B^{-1},x^1,\eta$ を更新 \Comment{$\beta(r)$ は逸脱していた側の境界へ}
\EndLoop

\Statex \textbf{局面B：切片問題~\eqref{eq:intercept}}
\State $z^1\gets c^\top x^1$；式~\eqref{eq:intercept}により $l^B,u^B$ を定める \Comment{局面Bでは $x^1$ と $z^1$ を固定する}
\State $x_N^0\gets$(状態 $L,U,Z$ に応じて $l^B_j,u^B_j,0$)；$x_B^0\gets A_B^{-1}(b-A_Nx_N^0)$ \Comment{1回の FTRAN}
\Loop \Comment{\eqref{eq:intercept}に対する第\ref{sec:dual-simplex}節の双対単体法}
  \State $V_B\gets\{\,i : x_{B,i}^0<l^B_{\beta(i)} \text{ または } x_{B,i}^0>u^B_{\beta(i)}\,\}$
  \If{$V_B=\emptyset$}
    \State \textbf{break} \Comment{切片問題の最適基底に到達}
  \EndIf
  \State $r\gets\operatorname{arg\,max}_{i\in V_B}\Delta_i/\sqrt{\gamma_i}$($\Delta_i$ は $l^B,u^B$ からの逸脱量)；$\rho\gets$ 逸脱の方向；$\alpha^\top,\sigma_j,\hat\alpha_j,\hat c_j\gets\cdots$
  \State $\mathrm{Eligible}\gets\{j\in N : l^B_j<u^B_j,\ \rho\,\hat\alpha_j<0\}$
  \If{$\mathrm{Eligible}=\emptyset$}
    \State \Return 「元問題は実行不可能」 \Comment{命題~\ref{prop:alg}(i)}
  \EndIf
  \State $q\gets\operatorname{arg\,min}_{j\in\mathrm{Eligible}}\hat c_j/|\hat\alpha_j|$；$\beta(r)\leftrightarrow q$ を交換するピボット；$B,A_B^{-1},x^0,\eta$ を更新
\EndLoop
\If{$z^1<0$}
  \State \Return 「元問題は実行可能かつ非有界」 \Comment{命題~\ref{prop:alg}(ii)}
\EndIf
\State $z^0\gets c^\top x^0$ \Comment{命題~\ref{prop:alg}(iii)，最適値}

\Statex \textbf{後処理}
\State 基底解を $x(M)=x^0+Mx^1$ とする($x^1$ は局面A，$x^0$ は局面Bの終了時のもの) \Comment{補題~\ref{lem:basic-slope}}
\While{$x_j^1\neq0$ なる非基底変数 $j$ が存在する} \Comment{高々 $K$ 回}
  \State そのような $j$ を一つ選び，補題~\ref{lem:cleanup}の主比検定で $t^\ast$ を求める($M$ のアフィン関数の $\succ$ 比較)
  \If{$t^\ast=M$}
    \State $x_j$ を有限な側(自由変数なら状態 $Z$，値 $0$)に置く \Comment{基底は不変，注~\ref{rem:state-F}}
  \Else
    \State $t^\ast=t_r$ となる行 $r$ で $\beta(r)\leftrightarrow j$ を交換するピボット；$\beta(r)$ を到達した有限境界に固定
  \EndIf
  \State $x^0,x^1,\eta$(ピボットした場合は $B,A_B^{-1}$ も)を更新 \Comment{目的関数値・主実行可能性・双対実行可能性はすべて不変}
\EndWhile
\State $x^{\ast\ast}\gets$ 得られた基底解 $x^0$($x^1=0$ ゆえ $M$ を含まない) \Comment{元問題の最適基底解(前処理後の座標系)}
\State \Return $\bigl(x^{\ast\ast}+t,\ \ z^0+c^\top t\bigr)$ \Comment{平行移動の逆変換．元の座標系での最適解・最適値}
\end{algorithmic}

\paragraph{正当性．}
Algorithm~\ref{alg:slope-intercept}の正当性は，第\ref{sec:M-infty}節の辞書式比較の理論によらず，直接示すことができる．$F$ を元問題~\eqref{eq:lp}(前処理後)の実行可能領域とする．

\begin{proposition}[Algorithm~\ref{alg:slope-intercept}の正当性]
\label{prop:alg}
Algorithm~\ref{alg:slope-intercept}は有限回で停止し，次が成り立つ．
\begin{enumerate}[label=(\roman*)]
\item 「実行不可能」を返すのは，$F=\emptyset$ のとき，かつそのときに限る．
\item 「実行可能かつ非有界」を返すのは，$F\neq\emptyset$ かつ $\inf_{x\in F}c^\top x=-\infty$ のとき，かつそのときに限る．
\item それ以外のとき，返される $x^{\ast\ast}+t$ は元問題の最適基底解であり，$z^0+c^\top t$ はその最適値である．
\end{enumerate}
\end{proposition}

\begin{proof}
\emph{局面A．}傾き問題はすべての上下限が有限な LP であり，初期基底は双対実行可能である(被約費用 $c$ の符号と状態の対応は命題~\ref{prop:dual-feasible-init}と同じ)．局面Aは傾き問題に対する双対単体法である．両側有限な変数は傾き問題では $[0,0]$ に固定されるが，これを比検定の候補に含めても双対単体法として正当であり，局面B以降のためにその変数の双対実行可能性が保たれる．費用摂動による辞書式規則のもとで局面Aは有限回で停止し，傾き問題は $x^1=0$ で実行可能であるから，停止時には最適基底に達する．$z^1=c^\top x^1$ はその最適値である．

\emph{局面B．}被約費用は $c$ と基底 $B$ のみで定まり，状態 $L,U,Z$ の符号条件は問題によらないから，局面Aの最終基底は切片問題に対しても双対実行可能である．また各非基底変数 $j$ は $x_j^1=l_j^1$(状態 $L$)，$x_j^1=u_j^1$(状態 $U$)，$x_j^1=0$(状態 $Z$，このとき $j$ は自由変数)を満たすから，\eqref{eq:intercept}の定義より $j$ は切片問題の有限な境界 $l^B_j$ または $u^B_j$ の上にあり，状態 $Z$ の変数は切片問題でも自由変数である．したがって局面Bは切片問題に対する通常の双対単体法として実行でき，有限回で「実行不可能」または最適基底に達して停止する．

\emph{切片問題と元問題の関係．}局面Aの終了時に $x^1$ は傾き問題の実行可能解であるから，$Ax^1=0$ かつ $l^1\le x^1\le u^1$ である．(a) $x^0$ が切片問題の実行可能解ならば，十分大きな $M$ で $x:=x^0+Mx^1\in F$ である．実際 $Ax=b$ であり，$x_j^1>l_j^1$ の成分では $x_j$ は $M\to\infty$ で下限(有限なら $l_j$，そうでなければ制約なし)を満たし，$x_j^1=l_j^1=-1$ の成分では $x_j^0\ge0$ から $x_j\ge-M$ にすぎないが元問題の下限は $-\infty$ であり，$x_j^1=l_j^1=0$ の成分では $x_j=x_j^0\ge l_j$ である(上限も同様)．(b) 逆に $x\in F$ ならば，十分大きな $M$ で $x^0:=x-Mx^1$ は切片問題の実行可能解である．実際 $Ax^0=b$ であり，$x_j^1=l_j^1=-1$ の成分では $x_j^0=x_j+M\ge0$，$x_j^1=l_j^1=0$ の成分では $x_j^0=x_j\ge l_j$ であり，$x_j^1>l_j^1$ の成分には下限がない(上限も同様)．いずれの場合も $c^\top x=c^\top x^0+Mz^1$ である．

(i)：(a)(b)より，切片問題が実行不可能であることと $F=\emptyset$ は同値である．
(ii)(iii)：局面Bが最適基底に達したとき $F\neq\emptyset$ である．$z^1<0$ ならば系~\ref{cor:phaseA}(i)より元問題は非有界である．$z^1=0$ ならば，(b)より任意の $x\in F$ に対し $c^\top x=c^\top(x-Mx^1)\ge z^0$ であり，(a)より $x^0+Mx^1\in F$ はこの値 $z^0$ を達成するから，$z^0$ は元問題の最適値である．このとき基底解 $x(M)=x^0+Mx^1$ は十分大きなすべての $M$ で元問題の上下限を満たし，状態は元問題に対して双対実行可能であるから，補題~\ref{lem:cleanup}の仮定を満たし，後処理により目的関数値 $z^0$ を保ったまま元問題の最適基底解 $x^{\ast\ast}$ が得られる．最後の平行移動の逆変換は第\ref{sec:shift-preprocess}節による．
\end{proof}

一方，第\ref{sec:two-phase}節により，局面A・Bの各反復は十分大きな $M$ に対する\eqref{eq:lpM}の双対単体法の正当な反復でもある(局面Aで傾きの同点を任意に解消するため，数値の $M$ での反復列との完全な一致は一般に失われる．第\ref{sec:chain}節)．すなわち Algorithm~\ref{alg:slope-intercept}は，人工上下限法の $M\to+\infty$ の極限での反復を，傾き問題と切片問題の2つの局面に分けて実行したものである．なお $z^1=0$ の場合には，後処理の代わりに既存の置き直し\cite{fourer1994,koberstein2005}を用いることもできる(第\ref{sec:known-two-phase}節)．

局面A・局面Bの主反復では，アフィン関数の辞書式比較 $\succ$ を一切用いない．局面Aでは傾き(整数係数の上下限 $0,\pm1$ に対する実数値)のみを，局面Bでは切片(通常の実数値)のみを比較する．$\succ$ が残るのは後処理の主比検定だけであり，そこでは $t_i$ と $M$ の傾きが一致する場合などに両成分が本質的に必要となる(注~\ref{rem:not-delta})．

\begin{remark}[辞書式比較による実行との比較]
\label{rem:impl}
Algorithm~\ref{alg:slope-intercept}を，(a$'$)(b$'$)の辞書式比較で主反復を1本の反復として実行する場合と比べる．反復あたりの主要な計算(BTRAN，FTRAN，ピボット行 $\alpha^\top$ の計算)は変わらず，反復回数も同点の解消法の違いを除いて同じであるから，計算量の削減は小さい．一方，次の利点がある(計算時間への効果は切り分けて計測していない．両者の比較は第\ref{sec:exp-structure}節)．
\begin{enumerate}[label=(\alph*)]
\item \textbf{実数計算への早期切り替え}：局面Bは，$v_i^{\pm,1}<0$ の側の上下限は存在しないものとし，$v_i^{\pm,1}=0$ の側は定数の逸脱量で判定し，アフィン関数の組を保持しない通常の実数値の双対単体法である．注~\ref{rem:absorbing}の切り替え時点($x_N^1=0$ への到達)が局面Aの終了時まで早まり，$x_N^1\neq0$ のまま停止する問題(非有界な場合や後処理を要する場合)ではこの差が大きい．局面Aでは切片 $x^0$ の更新も不要で，局面Bへの移行時に1回の FTRAN で計算すればよい．
\item \textbf{数値的頑健性}：辞書式比較 $\succ$ で必要だった，異なる行どうしの「傾きが等しいか」という浮動小数点の等号判定が不要となり，残るのは各行の $w_i^1$ の符号判定(通常の主実行可能性の許容誤差と同種)のみとなる．また\eqref{eq:slope}は右辺が $0$，上下限が $0,\pm1$ のみであり，$b$ の尺度に左右されない．
\end{enumerate}
懸念として，局面Aで傾きの同点を切片により選び分けていた効果が失われることが反復回数に与える影響は，経験的に確認する必要がある．Netlib での比較は第\ref{sec:exp-structure}節で述べる．
\end{remark}

\section{数値実験}
\label{sec:experiments}

Algorithm~\ref{alg:slope-intercept}を実装したソルバー ENOMOTO-Solver(Rust 実装，Python インターフェース)を，オープンソースの LP ソルバー HiGHS\cite{huangfu2018}の双対単体法と比較する．本節の目的は2つある．第一に，傾き・切片双対二段解法が，最急辺規則・BFRT・Forrest--Tomlin 更新などの標準的な技法と組み合わせて実用的な速度で動くことを示す．第二に，速度の差がどこから生じているかを，手法そのものの寄与と実装の寄与に分けて調べる．

\subsection{実装の概要}
\label{sec:exp-impl}

ENOMOTO-Solver の処理の流れは次の通りである．
\begin{enumerate}[label=(\arabic*)]
\item \textbf{プリソルブ}：Ruiz の均衡化\cite{ruiz2001}によるスケーリング，重複行・支配行の除去，境界の伝播，行・列シングルトン，等式ダブルトン，双対固定，implied free 列の代入，平行列の統合などを，不動点に達するまで繰り返す．
\item \textbf{標準形への変換}：第\ref{sec:shift-preprocess}節の平行移動を行い，各行にゼロ固定スラックを付ける．非有界な上下限は数値の $M$ に置き換えず，無限のまま保持する．制約行列が複数の連結成分に分かれる場合は成分ごとに解く．
\item \textbf{局面A・局面B・後処理}：Algorithm~\ref{alg:slope-intercept}のとおりに実行する．初期配置で無限側に置かれる変数がない($S=\emptyset$)場合は，局面Aを省く．脱退行の選択は双対最急辺規則\cite{forrestgoldfarb1992}，比検定は BFRT，基底行列の分解は Markowitz 規則\cite{markowitz1957}による疎 LU 分解と Forrest--Tomlin 更新\cite{forrest1972}による．
\item \textbf{仕上げとポストソルブ}：得られた基底を真の上下限とコストで検査する．浮動小数点誤差のために双対非実行可能な列が残った場合に限り，主単体法で仕上げる．最後にプリソルブを逆にたどって元の問題の解を復元する．
\end{enumerate}
既定の設定では，局面Aの終了時に $z^1<0$ であれば「実行不可能または非有界」を返して停止する(第\ref{sec:known-two-phase}節の既存の方法と同じ扱い)．設定により局面Bへ進ませれば，命題~\ref{prop:alg}のとおり両者を区別する．

\subsection{HiGHS にない実装上の工夫}
\label{sec:exp-features}

HiGHS 1.15.1 のソースコードと照合して，HiGHS の双対単体法にない，または扱いの異なる主な工夫を挙げる．括弧内の効果は，開発過程で Netlib の全問題に対して同一環境で行った比較計測の値である(後続の変更の前の値を含むため，目安として示す)．
\begin{enumerate}[label=(\alph*)]
\item \textbf{傾き・切片の局面構造}：HiGHS の双対フェーズ1も傾き問題と同じ補助問題を解くが，自由変数の上下限を $[-1000,1000]$ とする点が異なる．また HiGHS はフェーズ1の後に元の上下限へ戻してフェーズ2を行い，フェーズ1の最適値が負なら実行不可能と非有界を区別せずに停止する．本実装は，局面Bで切片問題を解き，後処理で人工境界上の変数を除く．
\item \textbf{FTRAN の融合}：1反復で必要な3本の FTRAN(加入列，双対最急辺規則の重み更新に用いるベクトル，BFRT でフリップした変数の寄与)を，LU 因子の1回の走査でまとめて解く．HiGHS はこれらを別々に解く．(フリップの反映の統合などを含む変更全体で，合計時間 $-4.6\%$，fit2p で $-17\%$．)
\item \textbf{縁付き LU 分解}：ほぼ密な列を分離し，Schur 補行列として別に扱う．(scrs8 で $-58\%$，ship04s で $-57\%$，shell で $-52\%$．)
\item \textbf{ピボット順の再利用}：再分解の際，前回の分解の列のピボット順を初期値として再利用する．HiGHS では同様の仕組みはホットスタートでのみ使われる．(合計時間 $-2.6\%$，$-4.3\%$(独立な2回の計測)．)
\item \textbf{再分解の判定}：数反復ごとに基底解の残差 $\|A_Bx_B-\text{右辺}\|$ を検査し，誤差の蓄積を検知したら再分解する．また，計算量の見積もりに基づいて再分解の時期を決める HiGHS の規則を移植したうえで，その閾値を Netlib で調整した．(閾値の調整により stocfor2 で $-39\%$，80bau3b で $-31\%$．)
\end{enumerate}
一方，プリソルブの各技法は HiGHS もほぼすべて備えている．また連結成分ごとの並列求解などの並列化は，Netlib の規模では発動しないか効果が見られないため，ここでは効果として主張しない．

\subsection{実験環境と計測方法}
\label{sec:exp-setup}

計算機は AMD Ryzen 7 5700U(8コア16スレッド)，メモリ 16\,GB，Windows 11 である．HiGHS は Python バインディング highspy 1.15.1 を用い，出力の抑制以外はすべて既定の設定とした(プリソルブあり，双対単体法は逐次版)．ENOMOTO-Solver もすべて既定の設定である．対象は Netlib\cite{gay1985}の LP 93問である．

計測するのは求解の呼び出しにかかる壁時計時間で，MPS ファイルの読み込みとモデルの構築は含まない．どちらのソルバーも，プリソルブとポストソルブの時間を含む．1回の計測ごとに新しいプロセスを起動し，最小の問題(afiro)を一度解いてスレッドプールの準備などの初回の固定費を済ませてから，対象の問題を1回解いて時間を測る．各問題について，HiGHS，ENOMOTO-Solver，および第\ref{sec:exp-structure}節で用いる辞書式比較版の順に交互に7回ずつ計測し，その中央値を用いた．計算機の負荷による揺らぎは小さくなく，同じ問題・同じ設定でも計測値は最大で数十\%ばらつくことがあった．

反復回数は，計時とは別のプロセスでの実行から数えた．ENOMOTO-Solver については，局面A，局面B，後処理のピボット，および真のコストでの仕上げ(第\ref{sec:exp-impl}節(4))の反復をすべて合計した．HiGHS については，双対フェーズ1・フェーズ2と主単体法による仕上げを含む単体法の反復回数の合計(\texttt{simplex\_iteration\_count})を用いた．

93問すべてで両ソルバーとも最適解を返し，最適値の相対差は最大 $4.4\times10^{-10}$ であった．

\paragraph{速度差の内訳．}
93問の反復回数の合計は，ENOMOTO-Solver が 92,835 回，HiGHS が 100,940 回である．ENOMOTO-Solver の内訳は，局面Aが 2,086 回，局面Bが 90,353 回，主単体法による仕上げが 396 回(12問)であり，後処理のピボットと真のコストでの双対単体法による仕上げは，どの問題でも0回であった．

時間の比の幾何平均を，反復回数の比と1反復あたりの時間の比に分解すると，次のようになる．
\begin{itemize}
\item \textbf{小さい問題}(非零要素数 5000 未満の49問)：反復回数の比は 1.01 で差がなく，1反復あたりの時間の比が 0.51 である．プリソルブや初期化を含む，反復以外の負担が小さいことが速さの主因である．
\item \textbf{HiGHS の時間が 0.1\,s 以上の17問}：反復回数の比が 0.77，1反復あたりの時間の比が 0.95 である．1反復あたりの時間はおおむね同等であり，速い問題の多くは反復回数が少ないことによる(cycle，nesm，pilotnov，pilot)．
\end{itemize}
逆に，遅い問題は2種類に分かれる．fit2p，d2q06c，25fv47 は反復回数が 1.2 倍前後多い．pilot87 と pilot は反復回数は少ないものの，1反復あたりの時間が約 1.5 倍かかる．反復回数の差は，プリソルブ後の問題の形，脱退行・加入変数の選択，BFRT の細部など実装の違いから生じるもので，次節で見るように局面構造によるものではない．1反復あたりの時間の差は，基底行列の分解と FTRAN・BTRAN の効率の差を反映している．

\subsection{傾き・切片の局面構造そのものの寄与}
\label{sec:exp-structure}

93問のうち，局面Aの反復が1回以上あったのは25問であり，局面Aの反復は計 2,086 回で，全反復の 2.2\% にすぎない．残りの68問では局面Aの反復は0回で，局面Bは元問題に対する通常の双対単体法に一致する(命題~\ref{prop:phaseB})．

同じ実装で，主反復を辞書式比較 $\succ$ による1本の反復(注~\ref{rem:impl})として実行した版と比較した．反復回数の合計は 92,835 回対 92,757 回で，差は 0.08\% である．局面Aが空でない25問に限ると，反復回数は 30,180 回対 30,102 回，計算時間の合計は 3.42\,s 対 3.42\,s であった．問題ごとの反復回数の差は，fit2p の $-105$ 回から greenbeb の $+157$ 回まで両方向に分布する．すなわち，注~\ref{rem:impl}で懸念した，局面Aで傾きの同点を切片で選び分けなくなることの影響は，Netlib では現れなかった．なお，局面Aの反復が0回の68問では両者の反復は完全に一致するが，計算時間の比の幾何平均は 1.02 であり，これが本実験の計測の揺らぎの目安となる．

以上より，Netlib での速度の優劣は，傾き・切片双対二段解法という手法そのものではなく，実装の違いによって決まっている．手法の利点は速度ではなく，数値の $M$ を用いずに双対単体法だけで3通りの場合を判別できるという性質の側にある．

Netlib より大規模な問題(Mittelmann の LP ベンチマーク\cite{mittelmann}など)での比較は今後の課題である．これらの問題では，ENOMOTO-Solver は HiGHS に及ばないと予想している．大規模で疎な問題では，FTRAN・BTRAN の右辺と解ベクトル，およびピボット行が極めて疎(超疎)になり，その疎性を活かす演算が計算時間を大きく左右するためである\cite{hall2005}．この点で，現在の実装は HiGHS に比べて次のように劣る．
\begin{itemize}
\item \textbf{超疎な三角解法}：HiGHS は FTRAN・BTRAN の $L$ と $U$ の4つの段すべてで，期待される結果の密度に応じて，深さ優先探索で非零パターンを先に求める超疎な解法\cite{gilbert1988,hall2005}に切り替える．本実装で超疎な解法を用いるのは FTRAN の $L$ 段と $U$ 段だけであり，Forrest--Tomlin 更新の行イータの段と BTRAN の $L^\top$ 段は零要素を飛ばせない．
\item \textbf{微小値の切り捨て}：HiGHS は絶対値 $10^{-14}$ 未満の値を零として捨てる．本実装は捨てないため，FTRAN・BTRAN の結果の「非零」要素のうち，この閾値未満のものが 80bau3b で 55\%，sctap3 で 75\% を占め，後続の演算の手間を増やしている．
\item \textbf{脱退行の選択と PRICE}：HiGHS は候補が多い場合に上位の候補だけを保持して走査を減らし(超疎 CHUZR)，ピボット行の計算も密度に応じて行方式と列方式を切り替える．本実装は既定で全候補を走査し，行方式だけを用いる．
\end{itemize}
これらは手法とは独立な実装の問題である．いずれも各局面にそのまま適用できるから，傾き・切片双対二段解法に固有の障害ではない．
